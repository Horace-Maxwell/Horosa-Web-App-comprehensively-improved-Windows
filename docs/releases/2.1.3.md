## Summary / 概览

`v2.1.3 Beta` syncs the latest Mac-side **BaZi time-display fix** into Windows. Toggling the BaZi "time algorithm" used to make the displayed "true solar time" jump (and the label was hardcoded). Now the **direct time and the true solar time are both shown as stable values** regardless of the toggle; the toggle only changes the *calculation basis*. It still includes the 2.1.2 AI Analysis rework and the 2.1.1 clean-machine runtime hardening.

`v2.1.3 Beta` 将 Mac 端最新的**八字时间显示修复**同步到 Windows。过去切换八字「时间算法」会让显示的「真太阳时」跳动（且标签写死）。现在**直接时间与真太阳时两个时间都恒定显示**，切换只改变「计算基准」。仍包含 2.1.2 的 AI 分析重做与 2.1.1 的干净机器运行时加固。

## What Changed / 本轮重点

- **BaZi time no longer jumps / 八字时间不再跳动**: `nongli.clockTime` (direct/clock input) and `nongli.solarTime` (always longitude + equation-of-time corrected) are computed independent of `timeAlg`. The pillar/luck calculation still follows the selected `timeAlg`.
- **Longitude is respected / 经纬度生效**: true solar time differs from direct time whenever the birth longitude is off the time-zone meridian (earlier to the west, later to the east), and by a few minutes even on the meridian (equation of time).
- **Primary fix is frontend / 主修复在前端**: BaZi is computed client-side via `lunar-javascript`, so the key change is in `astrostudyui/src/utils/baziLunarLocal.js`. A backend-only change would not show.
- **Backend kept consistent / 后端一致**: `astrostudysrv/.../model/BaZi.java` writes the same `clockTime`/`solarTime` into `nongli` (via `RealSunTimeOffset`), covering the local-calc-throws fallback and the AI export/analysis path. **`astrostudyboot.jar` was rebuilt from source** (multi-module Maven) so the change ships.
- **Unified display (4 places) / 显示统一**: `PaiBaZi.js` (new UI center header), `BaZiAppInfoPanel.js` (new UI right card), `BaZiLegacyView.js` (legacy XingQue header), and `BaZi.js` (AI structured snapshot) all show "直接时间 / 真太阳时 / 计算基准". Basis labels: `{0:真太阳时, 1:直接时间, 2:春分定卯时, 3:地方卯时}`.

## Data contract / 数据契约

| field | meaning | varies with timeAlg |
| --- | --- | --- |
| `nongli.clockTime` | direct / clock input time | no |
| `nongli.solarTime` | true solar time (always corrected) | no |
| `nongli.birth` | the calculation-basis time for the pillars | yes |
