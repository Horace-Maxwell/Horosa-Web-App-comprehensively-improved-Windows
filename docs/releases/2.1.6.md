## Summary / 概览

`v2.1.6 Beta` syncs two Mac-side fixes into Windows and batches in one Windows-only fix:
- **Qimen 奇门 calendar correction** (issue #4) — a low-level fix in the vendored Python engine `vendor/kinqimen`: month-pillar 月柱 now respects the precise 交节 (solar-term) crossing time, and 置闰 ju-determination uses the 超神接气置闰 solar term instead of an old lunar heuristic.
- **India chart map-pick** (issue #3) — `IndiaChartMain.js` `changeGeo` now sends a flat patch matching the parent `changeCond`.
- **Windows issue #2** (batched) — embedded Python/Java runtime isolated from a contaminated host environment (Win11 machines with system Python no longer fail to launch).

Pure Python (`vendor/kinqimen`) + frontend (`astrostudyui`) + Electron shell. **No Java change → `astrostudyboot.jar` was NOT rebuilt.**

`v2.1.6 Beta` 将 Mac 端的 **奇门历法底层修复** 与 **印度盘地图选点修复** 同步到 Windows，并合入本轮 Windows 侧 **issue #2 内置运行时环境隔离**。纯 Python（`vendor/kinqimen`）+ 前端 + Electron 外壳，**未改 Java，无需重建 `astrostudyboot.jar`**。

## What Changed / 本轮重点

- **奇门 `vendor/kinqimen/jieqi.py`**: `gangzhi` 月柱按 sxtwl 精确交节时刻校正（交节当日、交节前沿用前一日月柱；立春兼校年柱）；新增 `zhirun_jieqi`（超神接气置闰后的定局节气）。
- **奇门 `vendor/kinqimen/config.py`**: 重写 `qimen_ju_name_zhirun`（改用 `zhirun_jieqi` + `findyuen` + 既有局数表，弃用旧农历启发式）；新增 `dingju_jieqi`（拆补=历法节气 / 置闰=超神节气）。
- **奇门 `vendor/kinqimen/kinqimen.py`**: `pan()` 的「節氣」标签改用 `config.dingju_jieqi(...,option)`（置闰盘显示超神后的真实定局节气，拆补盘仍显示历法节气）。
- **奇门 `vendor/kinqimen/test_qimen_calendar.py`**: 新增 11 项回归测试（月柱边界 / 置闰 #62 / 拆补不变 / #43 / 闰大雪 / 整盘双法不崩）。
- **前端 `astrostudyui/src/components/astro/IndiaChartMain.js`**: `changeGeo` 改传扁平 `lon/lat/gpsLon/gpsLat`(+`tm`)，对齐 `AstroChartMain.changeGeo`（原把经纬度包成 `{value:...}` 与父级 `changeCond` 不符而报错）。
- **桌面 `desktop_installer_bundle/electron/service-manager.js`**（合并发布，Windows 侧 issue #2）: `sanitizeEmbeddedRuntimeEnv` 剥离宿主 `PYTHON*` / `_JAVA_OPTIONS|JAVA_TOOL_OPTIONS|JDK_JAVA_OPTIONS|CLASSPATH` 等污染变量；Python 以 `-E -s -X utf8` 启动；覆盖所有内置 python/java/`java -version`/jcmd 调用。

机制细节 / mechanism deep-dive: [`docs/qimen-calendar-fix-v2.1.6.md`](../qimen-calendar-fix-v2.1.6.md)。
