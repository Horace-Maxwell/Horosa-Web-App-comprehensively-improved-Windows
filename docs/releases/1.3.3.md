# Horosa 1.3.3

## 当前版本亮点 / Release Highlights

- 当前发布版本 / Current release: `v1.3.3`
- `v1.3.3` 修复三式合一第一次起盘后从星盘列表按钮切换命盘的同步问题。
- `v1.3.3` fixes Sanshi United chart-list button switching after the first plot.
- 再次选择已保存命盘时，右侧输入栏会自动更新，并触发太乙、遁甲、六壬合并结果重新计算。
- Selecting another saved chart now syncs the right-side input panel and recalculates Tai Yi, Dun Jia, and Liu Ren integrated results automatically.
- 星盘列表按钮点击现在会进入同一套刷新链路，不再依赖内部同步等待状态。
- Saved-chart list button clicks now enter the same refresh path even when no internal chart sync is pending.
- 旧三式合一案例恢复状态不再阻挡当前星盘列表命盘选择。
- Stale Sanshi case restore state no longer blocks a current saved-chart selection.
- Web 与 Windows App 共用同一套修复后的前端路径、运行时载荷、安装器与更新清单。
- Web and Windows App share the same fixed frontend path, runtime payload, installer, and update manifest.

## 下载 / Download

- 推荐安装包 / Recommended download: `Horosa-Setup-1.3.3.exe`
- 目标平台 / Platform target: Windows 10/11 x64
- 分发方式 / Delivery: NSIS installer with bundled runtime

## 安装 / Install

1. Download `Horosa-Setup-1.3.3.exe` from this release.
2. Run the installer on Windows 10/11 x64.
3. Start Horosa from the installed desktop shortcut or Start Menu entry.
