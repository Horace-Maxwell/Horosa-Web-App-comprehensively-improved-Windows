# Horosa v2.2.1 Beta — 发布说明

> Windows 端同步 macOS 端 v2.2.1（Mac main `e712784`），并**首次启用 Windows 应用内自动更新**（之前几轮在 Windows 侧自研 + VM 实测的成果一并随本版上线）。

## 本版内容

### 来自 Mac 同步（共享 `Horosa-Web/`，90 文件，0 冲突）
- **全局日界点 · 晚子时（时柱起干 第二开关）**：新增独立全局开关 `lateZiHourUseNextDay`（默认 `nextDay`，可选 `today`），只在 23:00–24:00 影响**时干**，与日柱换日开关 `after23NewDay` 完全独立。八字 / 奇门 / 太乙 / 六壬 / 金口 / 三式 / 紫微 / 数算（参评·河洛）等全技法一致。修复 `ChartController.getParams()` 等 8 个 controller + 3 个 model 的开关透传 bug。机制详见 `local/.../Horosa-Web/docs/global-day-boundary-v2.2.1.md`。
- **AI 供应商连通性**：① Anthropic 系（含第三方中转）`messages.content` 现带 `type:"text"`，修复 `missing field type` 的 503（Mac #9）；② 测试连接对未配置 / 未授权（401）给出可操作中文提示而非 URL 编码裸错误码（Mac #8）；③ `boundless/HttpClientUtility` 无代理环境变量时回退读系统 `http(s).proxyHost` 属性。
- **本地 AI 流式（Windows Issue #8）双修复**：`AIAnalysisProxyService` — (1) catch 块先 `QueueLog.error` 记录一级异常 + `sendEvent`/`completeWithError` 各自嵌套 try（修复一级异常被吞的可观测性 bug）；(2) `streamOpenAICompatible`/`streamAnthropic`/`streamGemini` 三处包 `withHeartbeat`，每 15s 写 `: keep-alive` 注释帧，慢速本地模型（Ollama 首 token 数十秒）不再被空闲超时切断。
- **偏好设置精修**：设置说明卡 / 关于弹窗样式统一（纯样式，不动数据绑定与语义色）。
- **软件内升级提示（共享 UpdateNotifier）**：随前端同步，但其 `isDesktopBridgeAvailable()` 仅在 Tauri（macOS）下激活；Windows（Electron）下自动 inert，更新仍由下方的原生更新器负责。

### Windows 侧（本版随车上线）
- **应用内自动更新（electron-updater + GitHub feed）正式启用**：每次打开自动检查 → 原生「发现新版」弹窗 → 下载（独立暗色进度窗口显示版本 / 百分比 / 已下载-总大小 / 速度）→ 「立即重启并安装」。**安装前先 `runtimeManager.stop()` 停掉内置 Python/Java 再 `quitAndInstall`**，避免 sidecar 占用 `app-runtime` 文件导致 NSIS 覆盖失败（这类应用最典型的不稳定根源）。后台检查对「已最新 / 错误」静默不打扰。打包链路新增 `write-app-update-yml.cjs` 生成 `resources/app-update.yml`（`--dir`+`--prepackaged` 拆分会跳过 electron-builder 自带生成）。VM 端到端实测 2.1.9 → 2.2.0 升级通过。机制详见 `docs/auto-update-windows.md`。
- **帮助菜单整理**：分组 + 补「自检修复 / 导出诊断 / 反馈问题 / 访问主页 / 关于星阙」，菜单栏保持可见。

### 含后端 Java 改动 → 已重建 `astrostudyboot.jar`
3 模块改动（`boundless` HttpClientUtility、`astrostudy` AIAnalysisProxyService/BaZiHelper/NongliHelper、`astrostudycn` BaZi/controllers/models）→ 重编链 `boundless install → astrostudy install → astrostudycn install → astrostudyboot clean package`（JDK17 + 内置 Maven）。核对打包 jar 内：`astrostudy` 含 `keep-alive`、`astrostudycn` 含 `lateZiHourUseNextDay`。

### 仍包含
v2.2.0 数算两新技法（邵子参评数 / 河洛理数）、调波盘绘制、风水 React 重写、AI 模型选择修复、Windows issue #7 tar 解析修复，及更早全部（详见 `docs/releases/2.2.0.md`）。
