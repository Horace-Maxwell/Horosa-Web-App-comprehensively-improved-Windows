# Horosa v2.3.0 Beta — 发布说明

> Windows 端同步 macOS 端 v2.3.0（Mac main `a649287`，相对上次同步基线 `e712784`）。这是一次**大版本更新**：占星地图（ACG）全面升级、辅盘新增「卜卦盘 + 择日盘」、河洛理数补全，外加 AI 系统代理（Windows Issue #9）等多项修复。

## 本版内容（来自 Mac 同步，共享 `Horosa-Web/`）

### 1. 占星地图 ACG 全面升级（前端 + Python + Java）
辅盘「占星地图」(`locastro`) 从旧的高德地图 + 迭代搜经度，整体换成 **D3-geo + 内置 GeoJSON + 赤经/赤纬解析法**：
- **算法重写** `astropy/astrostudy/acg/ACGraph.py`：GMST=`sidtime`、RA/Dec=`cotrans` 真交角；四轴线（ASC/DESC/MC/IC）全球连续 + 极区闭合；地理参考线（赤道/黄道/回归线）、Parans、Local Space、点击落点分析 `pointReport`。
- **新增端点** `/location/acgpoint`（`AcgController` + `AstroHelper.getAcgPoint`）；`getAcg` 改 `requestNoCache`（避免改后端后同盘命中旧缓存）。
- **前端** `components/acg/`：重写 `AstroAcg.js`，新增 `AcgD3Map.js` / `AcgPointPanel.js` / `interpretations.zh.js` / `world.geo.json`（Natural Earth 110m 开源国界，~168KB，随源码走）。
- **回归自检**：`astropy/astrostudy/acg/validate_acg.py` 用 Swiss Ephemeris `azalt()` 独立反验四轴线定义，内嵌 Windows python 实测 worst **0.000000°**（tol 1e-3，全 10 行星 × 3 算例通过）。

### 2. 辅盘新增「卜卦盘 + 择日盘」（纯前端，零后端）
引擎全部消费现成 `/chart` 字段，前端补算燃烧/角宫/月相/托勒密过滤 → 零新路由。
- 新增 `src/divination/{data / engine / horary / election}`（40 文件）、`components/{divination/DivinationChartShell, horary/{HoraryMain,HoraryJudgment}, election/{ElectionMain,ElectionJudgment}}`、`utils/divinationCaseSave.js`。
- **卜卦** 右栏 5 tab（裁决 / 征象 / 完成 / 时空 / 描述）：Sibly71 + Dorotheus43 + Sahl + Hephaistion + 盗窃 11 步；光线传递明确标注、月亮的故事、相位全览（仅托勒密五相位）、三分法则白话。
- **择日** 右栏 5 tab（总评 / 红线 / 分项 / 应期 / 建议）：13 模块 + 红线中文分级（严重/较重/中等/轻微）+ 0–100 评分 + 27 用事专属 + 本日逐时 / 未来 14 日扫描择优。
- **事件盘双向存盘**：Shell「存为事件盘」→ 事件盘库；列表「应用」→ 还原时间/地点/类别/设置（`AuxChartMain` 加 `componentDidUpdate` 才能被 applyCase 切子盘；`index.js auxChartTabs` 补全 `harmonic/horary/election`）。
- **AI 四环节同步**：导出技法 / 导出设置 / 分析挂载（`module:horary|election`）/ 快照。

### 3. 河洛理数补全（纯前端）
`utils/heluoLocal.js` + `components/shusuan/HeLuoMain.js` + `components/kinastro/KinAstroMain.js`：① 取化工法做成河洛**左栏 per-技法选项**（土王寄坤艮 / 直取四方伯，不入全局设置）；② 运盘流年/流月行加**精确节气交时 label**（纯展示·不改卦序）；③ 命运篇补 5 项判断（阴阳二数名 / 众宗众疾 / 顺反数+季节宜 / 正反对体凶 / 看命大法命格综合），主链算法零改。`scripts/_heluoTest.mjs` 96 断言全过。

### 4. ①–⑤ 修复
- **#9 内置 Java 走系统代理（治本，三处缺一不可）**：`boundless/HttpClientUtility.getHttpHost()` 加 `ProxySelector.getDefault()` 回退；`astrostudy/AIAnalysisProxyService.streamHttpClient` 加 `.proxy(ProxySelector.getDefault())`；**Windows 启动器** `service-manager.js buildJavaArgs` 加 `-Djava.net.useSystemProxies=true`（macOS 在 `start_horosa_local.sh` 加，Windows 外壳不共享需各自加）。无系统代理时 ProxySelector 返回 DIRECT、localhost 自动 bypass，行为不变。
- **六壬 / 三式合一 发三传顺序**：`components/liureng/ChuangChart.js getSangCuang` 把八专(`isBaZhuang`)移到遥克(`isYaoKe`)之后（按典籍九法：遥克第4法 → 八专第9法）。标准六壬与三式合一共用 `ChuangChart`，一改两修。
- **占星右栏 tab 下空白块**：`app.less` 内容容器填满 pane（覆盖占星/紫微/印度/果老 + 复用 AstroChartMain 的十三分盘/合盘/节气）。
- **风水页 UI**：选择栏对齐 + 文字间距 + 安全距离精修。
- **快捷功能 dock**：列网格 `repeat(8)` → 自适应 `grid-auto-flow:column`（兼容太乙等动态动作数）。
