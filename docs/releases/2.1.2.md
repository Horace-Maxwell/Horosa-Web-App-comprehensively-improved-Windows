## Summary / 概览

`v2.1.2 Beta` syncs the latest Mac-side **AI Analysis** rework into Windows: it fixes a serious wrong-chart context bug, adds per-chart headless recomputation for nine techniques, makes the mounted-context panel readable, and renders AI replies as proper Markdown. It keeps the full 2.1.1 clean-machine runtime hardening unchanged.

`v2.1.2 Beta` 将 Mac 端最新的 **AI 分析** 重做同步到 Windows：修复"挂错盘"严重 bug，新增 9 个命盘技法的按盘无头复算，重做挂载上下文面板，并把 AI 回复渲染为正常 Markdown。2.1.1 的干净机器运行时加固原样保留。

## What Changed / 本轮重点

- **Wrong-chart context fixed / 修复挂错盘**: selecting a chart and ticking a technique used to mount "the last chart you happened to view." Snapshot candidates whose birth/cast signature does not match are now hard-filtered out, so a mismatched chart can never be mounted.
- **Per-chart headless recompute / 命盘按盘无头复算**: each ticked technique is recomputed from *that chart's* birth data. Nine techniques are wired: Western chart, Indian (D1), BaZi, Ziwei, Firdaria, Primary Direction, Qizheng (Guolao), Suzhan, Germany/Midpoint.
- **Event charts never recompute by time / 事盘绝不按时间重算**: divination cases only mount the technique snapshot saved at cast time; ticking another technique shows "missing" rather than re-casting.
- **Context panel redesign / 挂载面板重做**: collapsible panels with full content, a status tag (ready / missing / pending) and a birth signature so you can verify which chart is mounted; newly added technique panels auto-expand.
- **Layout / 布局**: the session system prompt moved above the mounted-context card in the right column; the action button row moved beside the send button at the bottom.
- **History page / 历史页**: removed the two unused blank date inputs.
- **Markdown rendering / Markdown 渲染**: AI replies render via `marked` + `DOMPurify` (headings / bold / lists / tables / code / quotes), sanitized to prevent XSS — no more raw `**` noise.
- **Local kentang routing / 本地 kentang 端口**: for a local Java backend (`:9999`), all kentang/kin engines now resolve to the single chart service port (`8899`); the packaged desktop app was already correct via its explicit `kentangSrv` injection and is unaffected.
