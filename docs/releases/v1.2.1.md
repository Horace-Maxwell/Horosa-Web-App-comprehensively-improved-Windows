# Horosa v1.2.1

本次 1.2.1 补丁版延续 Windows 公开发布口径，并把最新的 Ollama AI 分析上下文预算修复同步进源码、自检链和发布说明。

## 重点更新

- 保持 `AI分析` 正式工作区入口与 `分析 / 历史 / 资料 / 模版 / 设置` 五页签结构
- 修复 Ollama 场景下 AI 分析上下文预算，避免上下文过长导致请求失败
- Web 与 Windows App 继续共用同一套 AI 分析前端与桌面联调链路
- 发布、自检与下载入口同步提升到 `v1.2.1`

## 发布资产

- `Horosa-Setup-1.2.1.exe`
- `latest.yml`
- 需要时可附带桌面离线压缩包或 manifest

## 发布说明

- `main` 现在对应 `v1.2.1` 源码口径
- latest GitHub Release 必须为 `v1.2.1`
- 源码仓库不提交可再生安装包、release 目录、node_modules 或本地 runtime 大包
