# Horosa v1.3.0

本次 1.3.0 发布线聚焦 Windows 端 `AI分析` 的完成度：把最新的 AI 分析界面整理、技法挂载、桌面安装验证与真实自检链路统一进正式发布口径。

## 重点更新

- `AI分析` 工作区继续保持 `分析 / 历史 / 资料 / 模版 / 设置` 五页签结构，并对齐最新的桌面端交付样式
- 新增并稳定化 `使用技法` 选择链路，确保命盘 / 事盘技法按所选项单独挂载，不再串入其他技法内容
- `AI分析` 现在会在缺少技法快照时自动按已保存案例结构后台补生成、保存回快照并立即刷新挂载状态，不再要求用户手动去原模块先生成一次
- 安装版 App 已补充真实 DeepSeek 联网 smoke：首字和后续流式 cadence 都纳入发布前验收，避免“首字快、后续一字一顿”的退化
- 修复 `AI分析` 流式输出换行被压平、正文渲染成一段以及回答被截断后不连续的问题，桌面后端 SSE 转发与前端续接逻辑已重新对齐
- 补齐 Windows App 的桌面端自检：安装包、已安装 app、DeepSeek live、资料、历史、模版、设置与技法挂载都纳入发布前验收
- Web 与 Windows App 继续共用同一套 AI 分析前端和上下文构建逻辑
- 发布、自检与下载入口同步提升到 `v1.3.0`

- `main` 现在对应 `v1.3.0` 源码口径

- 源码仓库不提交可再生安装包、release 目录、node_modules 或本地 runtime 大包
