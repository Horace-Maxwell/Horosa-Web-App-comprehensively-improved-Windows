## 本次更新

### 修复你报告的问题

- **修复 issue #24 / #25「更新后调用 gpt5.5 模型无法上传 / 内容总是上传失败」**（@wangzejin45-spec）—— 真因与 gpt-5.5 无关：聊天圆形发送按钮 `onClick={handleSend}` 直挂，antd 会把点击事件对象当第一个参数传给 `handleSend(overrideText)`，事件对象串化后就是你截图里的 `[object Object]`——气泡里显示它、AI 也收到它，看起来像「上传失败」。按 Enter 发送不带参数所以时好时坏。本版双保险修复：① 按钮改 `onClick={() => handleSend()}`；② `handleSend` 内 `overrideText` 只认字符串，非字符串一律回落输入框内容。
- **修复 issue #23「格式错误」**（@ecliptic0618，Gemini 400）—— 调用 Gemini 时 `temperature` / `maxOutputTokens` 等采样参数被放在请求顶层，而 Gemini 只接受它们在 `generationConfig` 内 → 上游返回 400「格式错误」。本版 `buildGeminiBody()` 显式把采样参数移入 `generationConfig`（重编 jar）。

### 排盘计算修正批（Python 引擎 · 从错到对，相关结果会变）

- **经纬度「度分」串解析**改标准 `deg + min/60`（原 `deg + 1.0/min` + else 分支 `*10` 均错：`'116e24'` 此前解析为 116.04 而非正确的 116.4）。
- **均时差表 3 区转录修正**（2/24；4/10–13 负零时符号；12/25）+ 时区「±HH:MM」解析支持分钟段（印度 +05:30 此前被当 +05:00，真太阳时差半小时）。
- **日返寻根**种子步改顺行弧（5–12 月生人按年初种子不再倒走到上一年）；**返照相位**先归一化到 [0,180]（跨 0° 合相不漏报）；骰子盘宫位判定支持跨 0° 宫。
- **合盘相位 / 映点 / 反映点**同口径归一化；**组合中点取短弧**（跨白羊点行星对不再翻到对宫）；**围攻判定**改独立 `pairOrb`；**时主星**改 `floor(经过时长)`；反平行第一伙伴漏加修复；恒星合相跨 0° 折回。
- ⚠️ 这些是**从错到对**的修正：月返/日返时刻、真太阳时（2/24、4/10–13、12/25 出生 + 半小时时区地区）、组合盘跨白羊点行星对、时主星等结果会变化。

### AI 分析 · 聊天与报告

- **聊天高级参数真正生效** —— 新增 `isOpenAiFamily()`：停止序列 / 频率·存在惩罚 / JSON 模式判定此前写 `protoFamily === 'openai'` 而预设实际取值是 `'openai-compatible'` → 判定永假、这些参数对 OpenAI / DeepSeek / Moonshot 等全部静默失效，本版起按家族判定。
- **思考档覆盖新推理模型** —— `applyThinkingLevel` 正则对齐 `gpt-5.5 / gpt-6 / gpt-7、o6 / o7`，不再静默丢档；AI 报告「思考档」新增「极高 / 最大」两档（Anthropic 按 max_tokens clamp 防 400）。
- **报告流中途错误不再吞**（半截内容不再被标「完成」）；**已取消请求不再补发**。

### Windows 壳层加固 9 项（本仓独有 · 高级工程师深扫产出）

1. **界面缩放持久化** —— 缩放值此前每次退出都保存但从未读回（`readWindowState()` 是死代码），每次启动复位默认。现启动时恢复上次缩放（Mac 端 Tauri `preferences.json` 同款修复的 Electron 镜像；窗口默认最大化策略不变）。
2. **AI 资料导入抗损** —— 单个不可读文件（OneDrive 离线占位 / 杀软锁定 / 无权限）此前会中止整批目录导入；现跳过 + 记日志。单文件 **64 MB** 上限防整批 base64 进内存 OOM。
3. **诊断报告导出加固** —— 目标目录不存在 / 被锁时返回明确错误信息（原静默失败）。
4. **AI 备份导出加固** —— 对话框分支补 `mkdir` + 错误捕获（与直接路径分支对齐）。
5. **「重启后端」串行化** —— 健康灯 / 错误 Modal / 离线横幅的重启按钮快速双击不再交错 stop/start（防止第二份内置 python+java 进程对泄漏到应用退出）。
6. **运行时修复顺序加固** —— 修复时先失效信任缓存（health / fast-path）再删运行时树：大树删除中途失败（杀软锁 / 磁盘满）不再留下「信任半删运行时」的缓存。
7. **退出清理计时器** —— 更新检查（15s/6h）与稳定性（45s）计时器在退出流程显式清理。
8. **winget manifest 真实发布日期** —— `ReleaseDate` 由生成时动态写入（原硬编码常忘改，v2.6.5 曾带着上一版日期）。
9. **发布自检堵假 10/10 漏洞** —— `SHA256SUMS.txt` 还停留在上一版本时改为响亮 FAIL（原仅提示「pending regen」并放行，若只补发布文档哈希忘了重生成 SUMS 会得到全绿假象、把过期校验文件发上线）。
