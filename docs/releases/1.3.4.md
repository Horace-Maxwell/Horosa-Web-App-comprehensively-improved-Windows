# Horosa 1.3.4

## Release Focus

- Current release / 当前发布版本: `v1.3.4`
- `v1.3.4` fixes the Dun Jia / Qimen tianpan heavenly-stem flying sequence.
- `v1.3.4` 修复遁甲 / 奇门天盘奇仪飞布逻辑。

## What Changed

- Standalone Dun Jia now flies the tianpan from the hour xun-head earth-palace source to the current hour-stem earth-palace target.
- Middle-palace participation follows the Windows sync package requirement: fly through Kun during the sequence, then preserve the middle palace value.
- Yang Dun and Yin Dun use the documented forward/reverse eight-palace order.
- Earth pan, doors, stars, gods, ju selection, calendar, ganzhi, sealed-board handling, and star-moving logic were left unchanged.
- Sanshi United continues to use the shared `calcDunJia()` result, so the integrated Dun Jia surface receives the same corrected tianpan.
- Qimen AI export and Sanshi AI snapshot text now read corrected `tianGan` values and nine-palace text.

## 更新内容

- 独立遁甲现在以时辰旬首六仪所在地盘宫为起点，以当前时干所在地盘宫为落点飞布天盘。
- 中宫按 Windows 同步包要求处理：参与飞布时按坤宫走，飞布结束后保留中宫原值。
- 阳遁、阴遁分别使用文档指定的顺逆八宫序列。
- 地盘、门、星、神、起局、历法、干支、封局、移星等稳定逻辑保持不变。
- 三式合一继续读取共享 `calcDunJia()` 结果，因此综合盘里的遁甲天盘同步获得同一修复。
- 奇门 AI 导出与三式合一 AI 快照现在读取修复后的 `tianGan` 与九宫文本。

## Installation

- Recommended download / 推荐安装包: `Horosa-Setup-1.3.4.exe`
- Platform: Windows 10/11 x64
- Distribution: NSIS installer with bundled runtime payload

1. Download `Horosa-Setup-1.3.4.exe` from this release.
2. Run the installer and open Horosa normally.
3. Existing app data is expected to remain in place during app replacement.
