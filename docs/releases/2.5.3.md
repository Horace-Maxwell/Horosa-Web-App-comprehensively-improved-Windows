# Horosa v2.5.3 Beta — 发布说明

> **小补丁版本**：修 v2.5.2 新引入的量化盘 90° 中点盘两处体验问题（盘下端被 Dock 遮挡、左右栏小窗口无法下滑）。v2.5.2 所有功能原样保留——v2.5.3 = v2.5.2 + 这两处 UX 修复，**已装 v2.5.2 的用户应用内自动更新即可拉到**。

## 本次更新

- **量化盘 · 中点盘下端被底部 Dock 遮挡 · 修复**
  盘体 size 之前只参考 `props.height`，没扣底部 Dock 占位 → 大屏（如 vh=1220）下盘 1000px、底沿距视窗只剩 84px 不够 Dock 高度，盘被压在 Dock 上看不清。现在改为三方钳位 `min(props.height, viewport − 260, 960)`：`viewport − 260` 同时扣顶栏 / sub-tabs / Dock / 留白；盘容器再加 `paddingBottom: 24` 安全距。

- **量化盘 · 左右两栏在小窗口下无法滚动 · 修复**
  左 / 右两个侧栏（设置 / 中点树 + 读数）原先无独立滚动，窗口高度不足时直接被截。现改：内层 div 包 `maxHeight + overflowY: auto`，**各栏可独立下滑**；同时监听 `window.resize` 实时重算 viewport，缩放窗口立即响应。

对应 Mac 端 commit `94b6e277c`，**纯前端单文件改动**（`astrostudyui/src/components/germany/UranianDialMain.js` +28/-6），无 Java / Python / 后端变化、无 jar 重建。

## 安装 / 升级

- 全新安装：下载 `Horosa-Setup-2.5.3.exe` 运行（自包含内置运行时）。
- 已装 **v2.2.1 至 v2.5.2** 用户：应用内自动更新会拉取本版（这正是从 v2.5.2 同版本覆盖发布改为 v2.5.3 patch release 的原因——electron-updater 按版本号比对，相同版本号不会触发更新）。
- v2.2.0 及更早需手动装一次。

上一版完整功能列表详见 [docs/releases/2.5.2.md](2.5.2.md)。
