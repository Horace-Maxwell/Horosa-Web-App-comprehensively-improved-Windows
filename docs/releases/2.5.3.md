# Horosa v2.5.3 Beta — 发布说明

> **v2.5.3 替代 v2.5.2 / supersedes v2.5.2** —— 与 macOS 端版本号统一，并在 v2.5.2 基础上补 90° 中点盘的两处布局修。v2.5.2 的全部新功能（90° 中点盘 / 主限法 Naibod / AI 聊天-嵌入解耦 + 高级参数 / Ollama 原生口让 `num_ctx` 真生效，修 #15 / 大六壬 + 三式合一 AI 挂载修复）原样保留。**已装 v2.5.2 的用户：启动后自动收到 v2.5.3 更新提示**；从 v2.5.1 或更早自动跳到 v2.5.3 的用户：以下是 v2.5.1 之后的完整变化。

## 本次更新

### 量化盘新增「90° 中点盘」技法（辅盘 → 量化盘）
汉堡学派 90° 中点盘：折叠盘与多环模数盘两种形态、三层叠盘（本命 / 行运 / 太阳弧）、八虚星（Cu / Ha / Ze / Kr / Ap / Ad / Vu / Po）、谐波盘基 H1..H512；可拖动的红色指针实时输出星体 / 中点 / 行星图读数与中点树。行运 / 太阳弧时刻与地点可独立调节，本命环锁定为最内圈。TNP 关闭时指针读数与中点树同步隐藏，太阳弧基准（Naibod / 1°）刷新页面持久化。

### 量化盘布局收尾（替代 v2.5.2 的临时版本）
- **中点盘下端不再被底部 Dock 遮挡**：盘体 size 由「单参数 `props.height`」改为三方钳位 `min(props.height, viewport − 260, 960)`，并给盘容器加 `paddingBottom: 24`；盘下沿与底部 Dock 之间留出安全呼吸距离。
- **左右栏小窗口可独立下滑**：左 / 右两个侧栏内层加 `maxHeight + overflowY: auto` 包裹，窗口高度不足（vh < 800）时各栏独立滚动，不再被遮挡或截断；监听 `window.resize` 实时重算 viewport。

### 主限法新增 Naibod 度数换算
主限法表格新增 Naibod 选项，与既有 Ptolemy / Alcabitius 链路完全独立、互不影响（Ptolemy / Alcabitius 路径逐字节对拍通过）。选 Naibod 时表格按 0.9856473 缩放日期、盘投射同步缩放、converse（反向）复用同一参数链。

### 主限法盘四角赤纬归正
修复 ASC / MC / DESC / IC 长期以来误以地理纬度作黄纬，导致赤纬越界（>23.5°）的问题；现在四个角一律按 `(lon, 0.0, obliquity)` 求赤经赤纬，结果与古典文献一致。

### AI 分析：聊天 / 嵌入模型解耦 + 高级参数
- **顶栏可独立指定聊天与嵌入模型**：例如聊天用 DeepSeek、嵌入用本地 Ollama bge-m3 这种混搭组合，不再被强制要求同一供应商（对应 Windows issue #13）。
- **「参数」抽屉新增高级参数**：思考档位 / temperature / top_p，按所选模型类型显示对应可调项；技法 Select 上移至「挂载」步骤之前，流程更顺。

### Ollama 本地推理：聊天 + 嵌入均改走原生口（修 Windows #15）
Ollama 在 OpenAI 兼容端点（`/v1/...`）下会**忽略 `num_ctx`** → 默认 4096 截断长玄学上下文；本版把 Ollama 聊天与嵌入分别切到 `/api/chat` 与 `/api/embed` 原生口，`num_ctx / num_predict / top_k / top_p / repeat_penalty` 嵌入 `options:{}` 后才真正生效。**界面里你设的上下文长度等参数现在会被尊重**，长盘面 / 多段提示词不再静默截断。其它供应商（OpenAI / Anthropic / Gemini / OpenRouter / 自定义）行为完全不变。

### 大六壬 / 三式合一 AI 挂载修复
此前因传入 null chartObj，`buildLiuRengLayout` 返 null 导致 AI 挂载内容为空；现在把完整 `result.liureng` 与 `/chart` 合并后再传入，大六壬 / 三式合一两个技法现在能正常挂入 AI 分析。

### 六爻接入时间起卦白名单
新增「起课时间」入口对六爻可用，**但仍守「永不按时间重算已存卦」铁律**——只对新时点起一卦，不会因时间变动重算你已保存的卦。

### 量化盘 AI 四同步
新增的 `[90°中点盘]` 段同时接入 AI 导出预设、导出设置版本（14→15）、AI 分析挂载、命盘 / 事盘储存——一处不漏。

### 中点盘 UI 收尾
距离标签从希腊符 Δ 改为短横线 `-`、TNP 关闭时指针读数和中点树同步隐藏 TNP 项、行运 / 太阳弧支持独立地点覆盖（留空 = 同本命）、左右栏布局优化避免截断换行。
