# Horosa v1.2.0

本次正式版把 Windows 仓库整理到可公开发布的口径，并把 `AI分析` 工作区作为正式产品面写入源码、桌面壳、自检链和发布说明。

## 重点更新

- 新增 `AI分析` 正式工作区入口，并固定为 `分析 / 历史 / 资料 / 模版 / 设置`
- 分析链路升级为真正流式输出，支持停止、重新生成、编辑上一条与分支会话
- 历史、资料、模版、组合、Provider 设置、备份恢复能力补齐
- Windows App 与 Web 继续共用同一套前端，同时保留桌面原生文件能力
- 修复默认缩放下 AI 工作区底部留白与滚动容器问题
- 仓库根目录补齐 README、LICENSE、治理文件、Issue / PR 模板与基础 CI

## 发布资产

- `Horosa-Setup-1.2.0.exe`
- `latest.yml`
- 需要时可附带桌面离线压缩包或 manifest

## 发布说明

- `main` 现在对应 `v1.2.0` 源码口径
- latest GitHub Release 必须为 `v1.2.0`
- 源码仓库不提交可再生安装包、release 目录、node_modules 或本地 runtime 大包
