# Horosa v1.1.1

本次正式版把主目录重新收口为唯一开发与发布真相，并将本轮已经验收通过的六壬、三式合一、遁甲与桌面端修复一起同步进新的 Windows 安装器。

## 重点修复

- 修复六壬与三式合一中反吟近克的规则链与显示语义，真案下三传、课式、盘式与判定路径保持一致
- 修复六壬盘中心文案布局，补齐十二式显示，不再出现重复叠字
- 修复遁甲主盘缩放、右栏滚动与超宽/偏矮窗口下的可见性问题
- 统一遁甲顶部八字颜色语义，并在主盘底部补齐状态图例，明确击刑、入墓、门迫、空亡与驿马提示
- 保留并验证此前已修复的节气盘、主限法、法达、六壬、三式合一与遁甲相关回归点
- 保留并验证桌面端关闭链、后台进程清理、再次打开、单实例与图标链修复，不回退旧功能

## 发布说明

- Latest Release 只保留 `Horosa-Setup-1.1.1.exe`
- 本版本继续使用完整离线安装器交付 Electron、Java、Python 与前后端资源
- 发布后会按 GitHub Release 下载路径再次回测本机安装链路，确保线上资产与主目录源码构建一致
