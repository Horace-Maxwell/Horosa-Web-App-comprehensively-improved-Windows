### AI 深度思考兼容（修 GitHub #16 — 后端 Java 改动，重建 jar）
- **真因不是超时**：① 后端丢弃 `reasoning_content`（思考期界面零输出被当作失败）；② deepseek-reasoner 被误发 `temperature` 等采样参数（可致 400）。
- **修法**（`AIAnalysisProxyService.java`）：`extractOpenAIStreamReasoning` 取 `delta.reasoning_content`（回退 `delta.reasoning`，Ollama 取 `message.thinking`）→ 流式发独立 `reasoning` SSE 事件；新 `isReasoningModel`（deepseek-reasoner / *-r1 / reasoning|thinking，与前端 `aiAnalysisProviders` 一致）对其经 `stripReasoningUnsupportedParams` **不发** temperature/top_p/presence/frequency/logprobs；4 个 stream 站点改走 `sendStreamWithRetry`——**仅首字节前**（连接/429/5xx）指数退避 + 尊重 Retry-After，**已出 token 的流绝不重试**（防重复计费）；`readErrorBody` 截断 1000→4000 字透传上游真因。单测 `AIAnalysisProxyServiceTest` 20 绿。
- **前端**：`aianalysis.js` 读流加「空闲看门狗」（有 token/心跳即重置，真静默 ~90s 才判卡死并给可重试提示）；`AIAnalysisMain.js` 接 `reasoning` 增量 → 独立「思考过程」可折叠区，仅展示/存档，**绝不回灌 messages**（DeepSeek 官方：input 含 reasoning_content = 硬 400）。

### 起课 / 命盘时间选中即刷新为「此刻」（修 GitHub #17 — 纯前端）
- 在「选择案例」里选中「起课时间 / 命盘时间」单选框，得到的是**点击此刻**的时间，而非打开软件（组件 mount）那一刻被 `useState` 惰性初值冻结的时间。修法：source 选择器 `onChange` 里选中时重算 `formatTimepointNow()`。

### 升级安装修复（修 GitHub #18 — Windows 独有，安装器层）
- **症状**：覆盖升级时报「**星阙 无法关闭。请手动关闭它…**」继而「**Failed to uninstall old application files: 2**」，升级从未成功，只能先卸载再装。
- **根因**：electron-builder 默认 `_CHECK_APP_RUNNING` 先发客气的 WM_CLOSE（被 `main.js` 的 `close` 事件 `preventDefault` 拦下做异步收尾，进程不立即退出），再用按 `$INSTDIR` 路径 / `USERNAME` 过滤的 taskkill——中文安装路径（「星阙」）令 PowerShell `.StartsWith($INSTDIR)` 过滤错配、USERNAME 过滤也可能漏，于是**关不掉 → `$INSTDIR\Horosa.exe` 被占用 → 卸旧失败**。
- **修法**（`assets/installer.nsh` 覆盖 `customCheckAppRunning`，路径无关的强力终止）：① `taskkill /F /IM Horosa.exe`（按映像名直杀主进程及其渲染/GPU/工具进程，释放 `$INSTDIR` 文件锁；**不带 `/T`**，避免误杀可能作为子进程的自更新安装器；**不带路径/USERNAME 过滤**，正是默认宏失效之处）；② 仅结束 Horosa 自己的内置 sidecar（路径含唯一标记 `embedded-runtime` 的 `java.exe`/`python.exe`，绝不动用户机器上其它 Java/Python；v2.5.4+ 的 Job Object 本已级联，这里兼顾旧版孤儿与 Job Object 失败的机器）；③ 有界校验+重杀循环（沉降 NTFS 句柄释放），仅在最后兜底才回退到手动关闭提示（`${Silent}` 静默自更新下不弹窗、不阻塞）。
- 由 `release_selfcheck.py` 哨兵守护（`customCheckAppRunning` + `taskkill.exe" /F /IM` + `embedded-runtime`），不可被后续同步悄悄回退。
