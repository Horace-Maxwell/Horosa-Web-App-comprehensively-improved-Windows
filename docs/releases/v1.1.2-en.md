# Horosa for Windows v1.1.2

> Relative-chart layout closure, installer-first Windows distribution, and a more product-grade release surface

## Overview

`v1.1.2` is a focused Windows release: small in scope, but much cleaner in delivery. The core fix is the remaining relative-chart layout issue where switching the five right-side subcharts could cut off the lower edge of the left chart. This release closes that gap and brings the regression into both the web self-check path and the installer smoke flow.

It is also the point where the Windows repository starts moving away from “stacked engineering notes” and toward a clearer GitHub-facing product surface. The latest release page, README, and versioned release docs now work together to answer the basic questions more cleanly: what should users download, what did this release change, and what should maintainers verify.

**Release date**: 2026-03-24

## Highlights

- **Relative-chart layout fix is fully closed**: the left chart is no longer clipped when switching the five relationship-chart tabs.
- **Viewport logic now uses the real remaining height**: the layout is no longer based on page-level height assumptions or arbitrary constants.
- **Regression coverage is stronger**: `relativechart` web checks and installer smoke tests now cover all five relationship-chart tabs.
- **One public recommendation remains**: ordinary users still only need `Horosa-Setup-1.1.2.exe`.

## Recommended Download

Regular users should download:

- `Horosa-Setup-1.1.2.exe`

That remains the intended Windows install entry. The installer is still the public distribution path, not a source-first workflow.

## Installation Steps

1. Download `Horosa-Setup-1.1.2.exe`
2. Run the installer
3. Complete the setup wizard
4. Open `星阙` from the desktop shortcut or the Start menu

## Major Improvements

### Relative-Chart Layout

- fixed the issue where the lower edge of the left chart could be cut off when switching the five right-side relationship-chart tabs
- switched the chart viewport handoff to a real remaining-height model instead of relying on full-page height or constant offsets

### Validation Pipeline

- added a `relativechart` web verification gate
- installer smoke now covers the comparison, composite, impact, spacetime midpoint, and Max relationship-chart tabs
- keeps the previously fixed Dunjia, Liu Ren, Sanshi, Jieqi, primary directions, firdaria, icon-chain, and shutdown regressions in the broader validation path

### Repository and Documentation Layer

- the Windows repository is moving toward bilingual README structure and versioned release documents
- the latest release surface now speaks more clearly to both ordinary users and maintainers

## Upgrade and Compatibility Notes

- public platform target: Windows 10 / 11 x64
- public install recommendation: `Horosa-Setup-1.1.2.exe`
- post-release verification should still use the actual GitHub Release download path to confirm that the online installer matches the repository-side build flow
