# Horosa v2.4.0 Beta — 发布说明

> **大版本同步**：把 macOS 端 `d8fe575`（v2.4.0）整轮成果搬到 Windows。基线 `fa6d9f3`（v2.3.1）→ `d8fe575`，3 commits / 42 共享产品文件（30 clean-port + 11 新增 + 1 个 3-way 合并）。含 Java + Python 改动 → **重建 `astrostudyboot.jar`**。

## 本次同步内容

### 西占六技法 — 全链路 AI（前端 + Python + Java → 重建 jar）

把六个「已能起盘但缺 AI 全链路」的西洋占星技法补成与主流技法同级的「**AI 分析挂载 + AI 导出（六张登记表）+ 事件盘储存**」完整体验：

- **十二分度盘**（Dodecatemoria / 12 分度）— `AstroDodeca.js`
- **主宰星链**（Dispositor 链 / 必然尊贵链）— `AstroDispositor.js`
- **寿命格局**（Lifespan / Hyleg-Alcocoden）— `AstroLifespan.js` + `divination/lifespan/{lifespanData,lifespanEngine}.js`
- **界行法分布**（Distributions / 界推运）— `AstroDistributions.js`
- **年龄推进点**（Age Point / 时间推进）— `AstroAgePoint.js`
- **世俗占星盘**（Mundane / 世俗盘）— `mundane/MundaneMain.js`

外加 **龙盘**（Draconic）辅盘实验室 `auxchart/AstroDraconicLab.js`。

「AI 分析挂载 ≠ AI 导出」是两套独立系统——本轮工程师级复审补全了 AI 导出侧的六张登记表（`utils/aiExport.js` auxchartMap / extractor / getAIExportAuditMatrix），与挂载侧（`utils/astroAiSnapshot.js` buildDodeca/Dispositor/LifespanSection + `utils/aiAnalysisContext.js` distributions/agepoint wired technique）对齐。

### 容许度（orbs / orbScale）随命盘存档

占星盘「容许度设置」抽屉（`AstroOrbSetting.js`，新增于 `pages/index.js`「容许度设置」Drawer）现随命盘存档与还原——镜像 `after23NewDay` 的五点对称透传（`models/user.js` / `utils/localcharts.js` / `models/astro.js`），默认 `undefined` 零回归，未触 pdMethod / 主限法。

### 共享后端（重建 jar）

- **Java `astrostudy` 模块**：`PredictiveController` 新增 `/predict/dist`（界推运分布）、`/predict/agepoint`（年龄推进点）；`AstroExtraController` 新增 `/astroextra/greatconj`（木土大合相，仅 startYear/endYear）、`/astroextra/draconic`（龙盘）；`AstroHelper` 加 Distribution/AgePoint/Draconic/GreatConj 常量 + getter。
- **Java `astrostudycn` 模块**：`ChartController.getParams()` 白名单加 `orbs` / `orbScale` 透传。
- **Python `astropy`**：`perpredict.py`（getDistributions / getAgePoint）、`agepoint.py`（**新建**，Koch 宫 `swisseph.houses_ex2(...,b'K')`）、`astroextra.py`（compute_great_conjunctions）、`thirteenthchart.py`、`perchart.py`、`websrv/webpredictsrv.py`（dist / agepoint 端点）、`websrv/webastroextrasrv.py`（greatconj / draconic）；`flatlib-ctrad2` 的 `object.py` / `tools/arabicparts.py`。

### macOS 专属（Windows N/A）

Mac 端「更新后无法自动打开」修复在 Tauri 外壳 `src-tauri/src/main.rs`（对已验签 runtime 在 start_runtime 前预写 fast-path 标记 + 取消首启冗余全量）。**Windows 更新流不同**：Windows 壳 = Electron `service-manager.js`（已有 fast-path / port-probe / trustedRuntime）+ `main.js` `quitAndInstall(true,true)`（静默 + 自动重启，自 v2.2.1 起 live、VM 验证过 2.1.9→2.2.0）。无「更新后首启反复卡」症状 → 按 Mac 交接文档指示**不移植 main.rs**。
