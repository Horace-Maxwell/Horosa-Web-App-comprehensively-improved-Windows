## Summary / 概览

`v2.1.8 Beta` is a **batch**: it syncs a group of Mac-side UI / divination-display and AI-streaming fixes, AND ships the previously-held Windows **Tier-1 installer slimming (1.14 GB → ~810 MB)**. Backend Java changed, so `astrostudyboot.jar` was rebuilt.

`v2.1.8 Beta` 是一次**合并发布**：同步 Mac 端一批 UI / 术数显示 + AI 流式修复，并带上此前暂存的 Windows **Tier-1 安装包减重（1.14 GB → ~810 MB）**。含后端 Java 改动，已重建 `astrostudyboot.jar`。

## What Changed / 本轮重点

**Mac-side fixes (synced):**
- **Ollama 流式不中断（GitHub issue #6）** — `boundless/.../interceptor/SseHelper.java`：`new SseEmitter(120000L)` → `(0L)`（去掉 AI 流式 120s 硬上限，慢速本地模型不再被掐断「停止生成」）；`astrostudy/.../service/AIAnalysisProxyService.java`：`buildJsonRequest` 仅在用户显式 `requestTimeoutMs` 时才加流式超时。
- **八字月柱交节边界** — `vendor/kinwuzhao/jieqi.py`、`vendor/kinastro/astro/bazi/calculator.py`、`vendor/kintaiyi/src/kintaiyi/config.py`：月柱按 sxtwl 精确交节时刻判定（交节前沿用前一日，立春兼校年柱），与 2.1.6 kinqimen 同款修法 + 新增 `vendor/test_month_pillar_boundary.py`（3 引擎 × 5 用例）。
- **太乙四柱随时间基准** — `components/taiyi/{TaiYiCalc,TaiYiMain}.js`：复用 `baziLunarLocal`，切「直接/真太阳」四柱重算 + 同显两时间。
- **主限法推运年数** — 前端 `components/direction/AstroDirectMain.js`、`components/astro/AstroPrimaryDirection(Chart).js`（控件、表头/页码）；Python `astropy/astrostudy/{perchart,perpredict}.py`（`pdYears` clamp 1–180 → `max_arc`）；Java `controller/PredictiveController.java`（`getParams` 白名单透传 `pdYears`）。
- **西洋盘符号几何居中** — `components/astro/{AstroChartCircle,AstroHelper}.js`：`dominant-baseline middle → central`（覆盖占星/合盘/辅盘/主限盘）。
- **UI 明暗/紫微/合盘/菜单修整** — `layouts/app.less`、`components/homepage/PageHeader.js`、`components/ziwei/ZWHouseSangHe.js`。

**Windows-side (batched in, previously held):**
- **Tier-1 打包减重 ~600 MB** — `stage-runtime.cjs` 从载荷裁掉 `appcds`/`wheels`/`bundle/wheels`/`node`/`maven`/`maven-extract`/`bundle/dist`（构建期/重复/可重建，运行时不用）。安装包 1.14 GB → ~810 MB。详见 `docs/PACKAGING_SIZE_AUDIT.md`。

机制细节 / mechanism: [`ui-and-time-fixes-v2.1.8.md`](../ui-and-time-fixes-v2.1.8.md)、[`bazi-month-pillar-boundary-fix.md`](../bazi-month-pillar-boundary-fix.md)。
