# Horosa 1.3.2

## 当前版本亮点 / Release Highlights

- 当前发布版本 / Current release: `v1.3.2`
- `v1.3.2` 补齐主限法福点在 AI 导出中的覆盖，让 Web、App、表格结果与导出快照保持同一套结果口径。
- `v1.3.2` completes Part of Fortune primary-direction coverage in AI export, keeping Web, App, table output, and export snapshots on the same result path.
- 福点仍作为迫星与应星进入 Core-Alchabitius / Ptolemy 主限法兼容分支。
- Part of Fortune remains available as both promissor and significator in the Core-Alchabitius / Ptolemy primary-direction compatibility branch.
- `Horosa原方法` 继续保持独立，不被兼容分支白名单污染。
