# Horosa v2.5.1 Beta — 发布说明

> **体验与稳定性更新**：同步 macOS 端 v2.5.1 的产品面（AI 分析页系统性翻新、技法全面接入 AI 挂载/导出、即时起盘入口、地点与时区全面校准），并修复部分 Windows 机器在开启系统代理时排盘失败的问题。v2.5.0 及更早全部功能保留。

## 本次更新

### AI 分析页系统性翻新
对话改为主流 Chat 式——空态居中气泡输入框，出文展开为限宽居中消息流；顶栏三步「配置 → 测试连接 → 对话」，技法 / 资料 / 系统提示 / 挂载预览收进「挂载设置」抽屉；每条回复新增「复制全文」「重新生成」，测试连接做成状态机（切换模型后重置、成功显绿）。换命盘 / 事盘后挂载内容**严格对应所选盘**（杜绝挂出上次看过的那张盘 / 卦）。

### 技法全面接入 AI 挂载 / 导出
西占全套推运（主限法盘 / 黄道星释 / 界推运 / 小限 / 太阳弧 / 日月返照 / 流年 / 十年大运 等）、数算（邵子参评数 / 河洛理数，**补齐逐年流年卦 / 岁运**）、演禽 / 策天飞星 / 皇极经世，均可挂载与导出；导出设置可逐技法逐段勾选。

### 新增「起课时间」「命盘时间」即时起盘入口
仅凭时间 + 地点即时起盘（默认此刻，可改）——起课时间对六壬 / 金口诀 / 奇门 / 太乙 / 三式合一 / 卜卦盘 / 择日盘，命盘时间对八字 / 紫微 / 星盘 / 各推运；两入口内置完整设置（地图选点 / 时区 / 命名 / 性别 / 一键保存为命盘·事盘）。摇卦类（六爻 / 统摄法等）永不按时间凭空起。

### 地点与时区全面校准
地点选择内置成熟 atlas：全球 3.4 万城市离线库（支持中 / 英搜索）+ 地图选点 + 手输经纬；坐标按标准度分秒（如 116°24′27″E）显示；时区可自动推断也可手动微调，并随命盘 / 事盘存档、贯穿 AI 挂载 / 分析 / 导出。修正西经 / 南纬 / 小负值坐标串（消除异地起盘的参数错、落宫差错）；**所有命 / 卜技法选地点或改时区即实时重排**（经度变 → 真太阳时变，时区变 → 起盘瞬时随之更新）。

### 排盘可靠性修复（Windows · GitHub issue #14）
修复部分 Windows 机器在**开启系统代理**（如 Clash / v2ray 等）时排盘报「本地排盘服务未就绪」「请求超时」「精确历法服务不可用」的问题：星阙内置后端对本地服务（`127.0.0.1`）的调用不再被系统代理拦截、绕行而稳定直连；同时对服务重启 / 启动窗口加透明退避重试，重启后立即可用。

### 其它
- 七政四余（Moira 模式）：星体居中于宿环两线之间、过近自动错开并连线标度数；庙旺标注如实显示。
- 紫微斗数：修复右栏信息面板底部空白；修复点击宫位后本命神煞被误改（本命神煞恒定）。
- 天文馆：「全屏」改为沉浸模式（隐藏两侧栏、画布铺满，带浮动「退出沉浸」按钮）。
- 占星页移除失效的「收合」按钮；星运页技法切换修复（点一次即进，不再先跳主限法）。
