# Horosa v2.5.5 Beta — 发布说明

> **同步 macOS 端 v2.5.5 产品面**：天文馆精修（投影对齐天文真值 + 每颗恒星可点击/按名搜索 + 文字更清晰）+ 流畅度优化 + 主限法铁律守护强化。**所有技法的命盘结果与 v2.5.4 完全相同**（默认 Alcabitius + Ptolemy 主限法路径经全 540 例逐字节验证与 v2.5.3 一致）。本版为**纯前端 + Python 测试夹具**改动，**无任何 Java / 算法 / 命盘数值改动 → 不重建 jar**（`astrostudyboot.jar` 维持 v2.5.4 基线）；运行时组件与 v2.5.4 一致（更新只替换桌面应用与前端，无需重新下载运行时）。v2.5.4 及更早全部功能保留。

## 本次更新

### 天文馆 · 投影对齐天文真值
- 星座 / 宫位 / 星宿区间的**名称不再偏移**；时间回放时黄道 / 星宿不再「先瞬跳再旋转」。
- 前端投影改用**逐日黄赤交角 + 视恒星时 + 大气折射**（Saemundsson），与后端 `swisseph.azalt` 完全一致（新增 BABYLON-free 投影核 `planetariumProjection.js`）；初始帧 / 暂停帧补算一次消除残余偏差。
- **二十八宿回到赤道**：宿度按距星赤经定位（赤道宿度），不再误贴到黄道（黄道只放星座 / 行星 / 宫位）。

### 天文馆 · 每颗恒星可点击 + 按名搜索
- 点击任意恒星（含暗星，射线夹角兜底）即弹出其**名称 / 拜耳编号 / 星座 / 星等 / 赤经赤纬**等信息。
- 搜索框支持**中文专名 / 英文专名 / HR 编号**自动补全并定位高亮（如「织女 / Vega」「天狼 / Sirius」），对齐成熟天文馆软件。
- 新增 `planetariumStarSearch.js`（最近星拾取 + 名称索引，纯函数）、`planetariumStarNames.js`（亮星中英专名表）。

### 文字更清晰
- 天文馆标签贴图按**设备像素比（DPR）超采样 + 三线性过滤**，缩放后不再发虚（`Engine` `adaptToDeviceRatio` + `setHardwareScalingLevel`）。

### 流畅度优化（不降级任何功能）
- 七政四余等**确定性纯计算技法**加「同参复用 + 在途合并」缓存：重开同一盘 / 来回切技法第二次起**瞬时复显**，命中结果与直连请求**逐值等价**（深拷贝返回）。
- 抽出通用请求去重工具 `services/_requestCache.js`（同参 LRU(48) + 在途合并）供重技法 service 复用；`services/qizheng.js` 的 `fetchKinastroQizheng` 包一层 `kinMem`。

### 主限法铁律守护强化（PD 代码未改动）
- 默认 Alcabitius + Ptolemy 输出经全语料实证与 v2.5.3 **逐字节一致（540/540）**。
- 校正一处**过期的回归测试基线**（golden 夹具 `golden_alcabitius_ptolemy_v253.ndjson.gz` 自 commit `883855d` 起就与代码不一致——重生自当前 PD 代码，**PD 算法不动**）。
- 新增守卫测试 `astropy/tests/test_planetarium_su28.py`（守二十八宿默认 REAL 模式是真赤道 ra≠lon）。

## 同步与构建口径（Windows）

- **同步范围**：仅 `Horosa-Web/` 业务改动——前端 `astrostudyui/src/components/planetarium/*`（`PlanetariumBabylon.js` + 新增 `planetariumProjection.js` / `planetariumStarNames.js` / `planetariumStarSearch.js` + 2 测试）、`astrostudyui/src/services/{qizheng.js,_requestCache.js}`，以及 Python 测试夹具 `astropy/tests/test_planetarium_su28.py` + 重生的 `golden_alcabitius_ptolemy_v253.ndjson.gz`。
- **无 Java 改动 → 不重建 jar**（boundless `isLoopbackTarget` #14 marker 仍在，apply.sh 适配 #8 自动 no-op）。**重建前端包**（`dist:win` 的 `build:renderer`）。
- Mac 同步基线 `54f3c42d`（v2.5.4）→ HEAD `5349b96b`（v2.5.5）。**下次 Mac 同步基线 = `5349b96b`**。
