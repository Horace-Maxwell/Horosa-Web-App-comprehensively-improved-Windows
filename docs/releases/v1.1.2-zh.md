# 星阙 Horosa for Windows v1.1.2

> 关系盘布局收口、Windows 安装器继续作为唯一公开入口、版本文档与发布说明升级

## 概览

`v1.1.2` 是一个“范围小，但交付更完整”的 Windows 正式版本。它聚焦在关系盘的最后一条可见布局问题上，把右侧五个子盘切换时左侧星盘底边被遮挡的问题彻底修干净，并把这条回归直接纳入网页与安装版 smoke。

这也是 Windows 仓库开始从“工程说明堆叠”转向“产品化 release 文档”的版本：最新 release 页面、仓库 README 与版本文档开始对齐，让普通用户和维护者都更容易理解应该下载什么、当前版本解决了什么。

**发布日期**：2026-03-24

## 本次亮点

- **关系盘布局问题正式收口**：修复五个子盘切换后左侧星盘底边被裁掉的问题。
- **真实高度口径统一**：关系盘改为按真实剩余高度向子盘传递 chart viewport，而不是继续依赖整页高度或常量偏移。
- **回归门槛更明确**：`relativechart` 网页自检与安装版 smoke 同时覆盖五个关系盘 tab。
- **公开入口继续保持单一**：普通用户仍然只需要下载 `Horosa-Setup-1.1.2.exe`。

## 推荐下载

面向普通用户，请下载：

- `Horosa-Setup-1.1.2.exe`

这是当前推荐的 Windows 安装入口。安装器仍然是公开分发主路径，不要求普通用户先理解源码目录或手工准备运行时。

## 安装步骤

1. 下载 `Horosa-Setup-1.1.2.exe`
2. 运行安装器
3. 按向导完成安装
4. 从桌面或开始菜单打开 `星阙`

## 主要改进

### 关系盘布局

- 修复关系盘右侧五个子盘在全屏、普通窗口与偏矮窗口下左侧星盘底边被遮挡的问题
- 切换为基于真实剩余高度的 viewport 计算方式，减少不同窗口条件下的布局漂移

### 验收链路

- 新增 `relativechart` 网页自检门槛
- 安装版 smoke 同时验证比较盘、组合盘、影响盘、时空中点盘、马克斯盘五个 tab
- 保留此前已经修好的遁甲、六壬、三式合一、节气盘、主限法、法达、安装版关闭链与图标链回归

### 仓库与文档层

- Windows 仓库开始采用更清晰的双语 README 与版本化 release 文档结构
- 最新 release 页面开始面向普通用户和维护者同时解释“下载哪个、为什么、这版修了什么”

## 升级与兼容

- 平台目标：Windows 10 / 11 x64
- 当前公开安装入口：`Horosa-Setup-1.1.2.exe`
- 发布后应继续使用 GitHub Release 实际下载路径做覆盖安装和 smoke，确保线上安装器与仓库构建口径一致
