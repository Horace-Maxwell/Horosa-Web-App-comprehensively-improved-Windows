# Horosa v1.1.2

本次正式版只针对关系盘做一个最小但完整的收口：把右侧五个子盘切换后左侧星盘底边被裁掉的问题修干净，并把这条回归直接加入网页与安装版 smoke。

## 重点修复

- 修复关系盘右侧五个子盘在全屏、普通窗口与偏矮窗口下，左侧星盘最下方星座被遮挡的问题
- 关系盘改为按真实剩余高度向五个子盘统一传递 chart viewport height，不再使用整页高度或随手减常量的旧口径
- 新增 `relativechart` 网页自检与安装版 smoke 门槛，覆盖比较盘、组合盘、影响盘、时空中点盘、马克斯盘五个 tab
- 保留并继续验证此前已经修好的遁甲、六壬、三式合一、节气盘、主限法、法达、安装版关闭链与图标链

## 发布说明

- Latest Release 只保留 `Horosa-Setup-1.1.2.exe`
- 本版本继续通过主目录源码直接构建网页与 Windows 安装器
- 发布后会按 GitHub Release 实际下载路径再次覆盖安装并 smoke，确保线上安装器与主目录构建口径一致
