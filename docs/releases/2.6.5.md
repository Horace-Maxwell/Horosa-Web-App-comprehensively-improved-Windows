# Horosa v2.6.5 Beta — 发布说明

> **同步 Mac 端 v2.6.5**：合盘 / 关系盘交互链全面重建（5 子盘全可用）+ AI「起课时间」挂载 8→13 技法 + Python 排盘数值经纬度容错 + 全 22 模块导航搜索关键词 + 关于框真图标 + 一批小修。**本版无后端 Java 改动 / 无需重建 jar**——合盘端点恢复 = 前端把请求路由回 Java modern-chart 后端（`:9999`），`ModernChartController` 自 v2.6.4 已在；沿用 v2.6.4 的 `astrostudyboot.jar`（324,254,239 B，selfcheck 已核 jar 标记 + 内容字节不变）。命盘计算默认行为与 v2.6.4 字节级一致；v2.6.4（恒星黄道 47 岁差全栈 + 西洋月宿 + 印占补齐 + AI 四同步 + AI 报告 v1 + 启动健壮性 + 修 #21）及更早全部功能全部保留。

## 本次更新

- **合盘 / 关系盘交互链全面重建** —— 五个子盘（合盘 Synastry / 组合中点 Composite / Marks / 时空盘 Time-Space / 关系评分）全部恢复可用。全链路修复：排盘请求路由回 Java modern-chart 后端（`:9999`，此前误打到 Python `:8899` 导致空盘）、`ResizeObserver` 实测容器高度不再塌陷、`chartStyle / dispatch / onChange` 三件套全透传、`handleRelativeOnChange` 直写 fields、`paramsToFields` 不再覆盖宫制 / 黄道、删除 `hidezodiacal / hidehsys` 历史标志、黄道 Select 局部 CSS 定宽 50/50。
- **AI「起课时间」挂载 8→13 技法** —— 太玄筮法 / 荆决 / 五兆 / 神易数四种确定性起课术各新增 `buildXxxSnapshotForFields(fields, opts)` 快照构造器，其起课盘现可挂入 AI 分析；`aiAnalysisContext.js` 加 5 imports + 5 switch case，`TIMEPOINT_CASTABLE_SET` / `listAnalysisTechniqueOptions` 两份同步含全 13 项；`buildFieldObject` 兜底 `record.divTime`；`techniqueMountSettings.js` 四法升 `kind:'payload'`；`AIAnalysisMain.js` 一键挂载文案 / drawer hint 更新。
- **Python 排盘数值经纬度容错** —— `astropy/astrostudy/helper.py` 的 `convertLonStrToDegree / convertLatStrToDegree` 加 `isinstance(lon/lat, (int, float))` 数值分支；`astropy/astrostudy/jieqi/realsuntime.py` 的 `getBaseLonByZone` 加 `isinstance(zone, (int, float))` 数值时区分支。地图选点存的是浮点经纬度 / 时区，旧代码假设字符串输入会在 `.split()` 等处抛错；本版数值路径直接采用、字符串路径原样，修地图选点排盘的潜在 crash。
- **顺手修** —— `HomePageSetup.js` + `pages/index.js` 全 22 模块 `navigationPages` 补 `keywords`（导航搜索可命中别名）；`PageHeader.js` + 新增 `appicon.png` 关于框换真图标；`AstroPersianDirected.js` 应期年数联动表格；`UranianDial.js` glyph `stroke:none`；`app.less` 测天字重 700→500 / 800→600；`AIAnalysisMain.js` source select 刷新案例；`AstroEphemeris.js` + `AstroExtraCommon.js` + `PlanetariumBabylon.js` + `xq-ui/styles.less` 一批小修。
- **测试** —— jest **658 通过 / 70 suites**（v2.6.4: 638）；新增「`listAnalysisTechniqueOptions(timepoint)` 必含全 13 项」断言 + `techniqueMountSettings` `SECTIONS_ONLY` 收紧到 4 项 + 首页导航搜索 / 波斯向运用例；service-manager + update-signature **39 通过**。

- **同步范围**：Mac 端 `Horosa-Web/` 业务改动（合盘交互链 7 文件 + AI 起课时间 6 文件 + Python 2 文件 + 导航搜索 / 图标 / 小修若干）。Mac `Horosa_Desktop_Installer/`（Tauri 外壳 + 其 runtime 簿记）是 Mac 独有，**不同步**。

- **无新 npm 依赖**：`astrostudyui/package.json` 依赖块 `15a21bb..dbac0ed` 零变化。
- Mac 同步基线 `15a21bb`（v2.6.4）→ HEAD `dbac0ed`（v2.6.5）。**下次 Mac 同步基线 = `dbac0ed`**。
