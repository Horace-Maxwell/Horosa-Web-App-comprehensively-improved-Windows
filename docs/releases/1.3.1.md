# Horosa v1.3.1

Horosa v1.3.1 synchronizes the Windows release with the verified Pars Fortuna primary-direction implementation. This release keeps the web and Windows app paths aligned so the installed desktop product uses the same backend, frontend, AI export, and runtime behavior.

## Highlights

- Added Pars Fortuna support to the current primary-direction compatibility branch.
- Pars Fortuna now appears as both promissor and significator in the Core-Alchabitius / Ptolemy workflow.
- Synchronized Python backend, Java API wiring, shared frontend table/chart logic, AI export aliases, runtime bundle, and installer to `pd_method_sync_v8`.
- Kept `Horosa原方法` independent from the compatibility branch.
- Rebuilt the Windows static web bundle and Windows installer so the installed app no longer reuses older primary-direction runtime assets.

## Validation

- Python integration checks passed.
- `refetch_pf_current` sample comparison matched the expected reference range.
- Frontend tests passed: 25 suites / 144 tests.
- Browser validation passed with Pars Fortuna rows present as both promissor and significator.
- Installed runtime payload was inspected for `pd_method_sync_v8`, Pars Fortuna markers, and absence of old `pd_method_sync_v6` / `pd_method_sync_v7` in production text paths.
