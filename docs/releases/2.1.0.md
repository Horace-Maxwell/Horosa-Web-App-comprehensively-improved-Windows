# Horosa 2.1.0 Beta

## Summary

- Current release / 当前发布版本: `v2.1.0 Beta`
- Installer / 推荐安装包: `Horosa-Setup-2.1.0.exe`
- Platform / 支持平台: Windows 10/11 x64
- This release should be published with the standard Windows asset set only: installer, blockmap, `latest.yml`, and `SHA256SUMS.txt`.
- The installer is intentionally unsigned for this build because the current request was to package without signing.

## Release Theme

`v2.1.0 Beta` is the Windows port of the latest Mac 2.1.0 beta product surface, adapted for Windows Web/Desktop delivery. It keeps the earlier Windows 2.0 parity and Qimen fixes, then adds a broader traditional-method backend layer, structured local data management, AI export coverage, startup-console polish, window/settings persistence, and installer hardening for clean Windows machines.

`v2.1.0 Beta` 是 Mac 2.1.0 beta 最新产品面的 Windows 对齐版，并针对 Windows Web/Desktop 交付做了运行时和安装器适配。它保留此前 Windows 2.0 对齐与奇门修复，再继续加入传统命法/卜法后端、结构化本地数据管理、AI 导出覆盖、启动控制台打磨、窗口/设置持久化，以及面向干净 Windows 机器的安装器加固。

## Main Changes

- Added and normalized backend integrations for Taiyi, Jin Kou, Huangji/Wangji, Wuzhao, Taixuan, Jingjue, Shenyishu, Kin Astro, Qizheng, Qimen, and related specialty methods.
- Sanshi United routes Qimen and Taiyi through the kentang backend while LiuReng stays on the existing local LiuReng implementation.
- Unsupported Qimen month-chart options were removed from Qimen and Sanshi surfaces instead of silently falling back to an older local calculation.
- Chart management and case management preserve new-method inputs, tags, snapshots, raw backend payloads, JSON import/export, and reopening behavior.
- AI export reads structured backend data and exposes selectable export groups for supported techniques, tabs, and pages.
- User settings, desktop window size, and necessary UI choices persist across close/reopen and app updates.
- The desktop startup console uses the final Xingque icon, shared Daily / Offline Ready / Failed states, real-time backend progress, and no duplicate status panels.
- Window restoration avoids the previous launch-size flash, and the test harness no longer mutates the visible Electron window size.
- App-wide light/dark contrast, dropdowns, overlays, loading states, management lists, and export controls were rechecked and polished.
- Ziwei four-transformations chart hides star brightness labels so they do not overlap star names; Ziwei Sanhe and Cetian Flying Stars still show brightness where appropriate.
- The new XingQue Bazi fine-chart upper content area can scroll without moving the fixed luck/flow selection area.
- Feng Shui Naqi loading, relationship chart, Jieqi, primary direction, Firdaria, LiuReng, Sanshi, and Dunjia smoke cases remain covered.

## Windows Delivery

- NSIS assisted installer with custom directory selection.
- Directory creation/write validation and Windows elevation support when required.
- Bundled Python runtime, Java runtime, Node/Web assets, frontend `dist-file`, Java backend jar, offline Python wheels, and packed runtime payload.
- Normal users do not need Python, Java, Node.js, Maven, Visual Studio Build Tools, or a repo checkout.
- First launch can be slower while the bundled runtime is extracted and verified. Warm launches reuse the local runtime cache and were checked under 10 seconds.
- The Windows package avoids Mac-only command files and Mac runtime folders as release dependencies.
