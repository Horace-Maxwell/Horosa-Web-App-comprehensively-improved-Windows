## Summary / 概览

`v2.1.5 Beta` syncs the latest Mac-side **AI Analysis page hardening** into Windows: provider switching/auth, send-safety, and surfacing of previously-silent failures. Mostly frontend with a small backend (`AIAnalysisProxyService.java`) change, so `astrostudyboot.jar` was rebuilt. Includes all prior 2.1.4/2.1.3/2.1.2/2.1.1 work.

`v2.1.5 Beta` 将 Mac 端最新的 **AI 分析页全面修复** 同步到 Windows：供应商切换 / 鉴权、发送安全、静默失败透出。以前端为主 + 后端少量（`AIAnalysisProxyService.java`），故已重建 `astrostudyboot.jar`。

## What Changed / 本轮重点

- **Backend `AIAnalysisProxyService.java`** (astrostudy module): `buildAuthHeaders` no longer adds `Authorization: Bearer` for **gemini** (native Gemini uses the URL `?key=`; adding the header caused `ACCESS_TOKEN_TYPE_UNSUPPORTED`); **custom** providers can override with `providerOptions.authHeaderName` / `authPrefix` (both added to the body-preserved keys); the reasoning-model prefix list adds `o5`.
- **Frontend `components/aianalysis/AIAnalysisMain.js`** (multiple): provider cards clickable + a "set current" button; switching provider type clears the stale apiKey; deleting the current provider auto-selects another; switching/deleting a session aborts the active stream first; a concurrent-send guard; auto-scroll to bottom; embedding/chunking failure prompts; Markdown parse failure falls back to plain text.
- **Frontend `services/aianalysis.js`**: requests + stream honor `providerOptions.requestTimeoutMs` (`resolveRequestTimeout`, 1s–10min, default 120s); stream `catch` flushes the parser so a final `error` event surfaces.
- **Frontend `utils/aiAnalysisStore.js`**: `saveUiPrefs` logs a localStorage-quota failure instead of silently swallowing it.
