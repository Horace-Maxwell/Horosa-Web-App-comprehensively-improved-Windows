# Horosa v2.5.0 Beta — 发布说明

> **大版本同步**：把 macOS 端 `1c463718`（v2.5.0，5 分支收敛 + 白屏热修）整轮成果搬到 Windows。含 Java + Python 改动 → **重建 `astrostudyboot.jar`**（boundless + astrostudy + astrostudycn → boot）。

## 本次同步内容（5 分支收敛）

### 1. 西占推运补全 7 技法 + Balbillus + 福点整宫制（前端 + Python + Java → 重建 jar）
- **波斯向运 / 行星弧 / Vedic 推进 / Jayne 赤纬向运 / 行星年龄 / 真 129 年法 / Balbillus**，全部接入 AI 分析挂载 + AI 导出。相位美化 + 映点/反映点（antiscia）恢复。
- **福点整宫制（Part-of-Fortune whole-sign）全局宫制**：`perchart.py` 中 `house.hsys` 须设 `const.HOUSES_WHOLE_SIGN`（否则 flatlib `inHouse` 加 −5° 偏移致落宫差一）。
- Python 新建 `astrostudy/{symbolicdir,yearsystem129}.py`；Java `PredictiveController` 新增 `/predict/planetaryarc` · `/predict/persianchart`。

### 2. 时区/夏令时（DST）自动校正（纯前端，新增依赖 `tz-lookup`）
出生/命盘/事盘三表单按经纬度离线求 IANA 时区并自动校正夏令时：`utils/timezone.js` + `components/comp/DstZoneIndicator.js` + ChartFormData/ChartData/CaseData。

### 3. 金口诀解读层 + 七政四余 Moira 还原度（纯前端）
金口诀神煞判语/四位生克/应期/分类用神/刑冲合害破/太玄数；七政四余 28 宿环、显示选项、多 tab、大限、神煞判语。

### 4. 紫微斗数运限深化 + 六壬 Phase4（前端 + Java astrostudycn → 重建 jar）
- 紫微右栏新增「运限 / 格局」两 Tab：八字大运式级联运限（大限▸流年▸流月▸流日▸流时 + 小限独立段）+ 多层四化卡 + 格局自动识别（34 格）。后端 `/ziwei/birth` 返 `patterns[]`，**新增 `/ziwei/luck`**；修 `ZiWeiHelper.getSmallDirectioinHouse` 女命分支历史 bug。前端 `ziwei/{ZWLuckPanel,ZWPatternPanel}.js`（新增）+ `ZiWeiMain/ZWChart/ZWHouse/…`；Java `astrostudycn` `ZiWeiController`/`ZiWeiHelper` + `ZiWeiLuck.java`/`ZiWeiPattern.java`（新增）+ `ziweige.json`/`ziweiliuchangqu.json`（新增资源）。
- **六壬 Phase4**（纯前端 castOverride）：七政接入 + 起课法 / 换将 / 分昼夜（`lrzhan/*` + `liureng/{LRCommChart,LRConst}.js`）。

### 5. 启动机制稳健化（根治「端口被占用 / 后端未启动」）
- **共享前端**：新增 `utils/serviceStatus.js` / `utils/chartFetch.js` / `components/common/ServiceStatusBanner.js`（挂 `layouts/app.js`）；`request.js` 加 `fetchWithRetryConnRefused`（SSE `requestStream` 绝不重试）；四引擎（dunjia/taiyi/jinkou/qizheng）走 `fetchChartWithRetry`；`warmHorosaRuntime.js` 加 `HOROSA_WARM_MINIMAL`。
- **Windows 启动器镜像（`electron/service-manager.js`，与 macOS main.rs 不共享）**：`launchServicesWithPortRetry`（端口 bind 冲突换口重试 ≤5；崩溃处理器仅端口监听后挂载；web 无独立端口 → 「web 不入重试环」天然成立）+ `isPortConflictError`（精确 token，绝不裸匹配 `port`）+ `-Dhorosa.runtime.owner=horosa-desktop`。最小热身由现有 `waitForChartProbe` 满足。

### 6. 星运/主限法白屏热修
`AstroPrimaryDirection` 等：修旧存盘 `pdMethod` 触发的无限 `setState` 导致整页白屏（Mac `1c463718`）。

## Windows 端适配（与 macOS 不共享）
- **构建适配**：`astrostudyui/scripts/umi-runner.js` + `loadCryptoDeps.js` + `scripts/vendor/` + `package.json` 的 umi-runner build 脚本（macOS 用 bash `export NODE_OPTIONS … && umi build`，Windows cmd 跑不了）；`astropy/requirements.txt` 去掉 `flatlib==0.2.3.post3` 钉（flatlib 由 vendored flatlib-ctrad2 经 sys.path 注入，非 pip）。
- **产品源 Windows-ahead 修复（重建）**：`utils/windowSizePersistence.js` 的 `isDesktopShellWindow`（Electron 自管窗口边界，桌面壳内不做 web 层窗口持久化，避免启动抖动；用 `window.horosaDesktop` 信号，镜像 macOS `isTauriWindow`）；`pages/index.js` 的 `ensureField`（防御性字段保护 + `lat` 字符串化，防数值 lat 触发 `.toLowerCase()` 崩溃）。`ziwei/ZWHouse.js` 策天飞星亮度（Mac 共享逻辑等价）、`app.less` 滚动条等随 Mac 源同步。
