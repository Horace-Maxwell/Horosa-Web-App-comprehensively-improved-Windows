> **同步 Mac 端 v2.6.3**：AI 分析一轮深度打磨（聊天 UX / 设置 / Provider 矩阵 / 视觉 / 用量 / JSON 模式全补齐）+ 七政四余「政余格局/相位」补 AI 出导/挂载 + 五兆/太玄/荆诀/神易数补 AI 挂载 + 分至盘样式按钮修复 + 多处稳定性修复。**后端 Java 改动**（`AIAnalysisProxyService.java` +344/-9：SSE `usage` 事件、Gemini 视觉、停止序列/JSON 模式/思考档显式映射、`isReasoningModel` 覆盖 gpt-5/6/7 与 o1/3/4/5/6/7）→ **已重建 `astrostudyboot.jar`** (324,253,974 B)。所有技法命盘计算与 v2.6.2 字节级一致；v2.6.2 的 #18 升级安装修复 + v2.6.1 前所有功能全部保留。**修复 Windows issue #20**「AI 工具挂载新内容易被截断 + 太阳返照 AI 用本命盘信息」。

## 本次更新

- **AI 分析 · 聊天 UX**：代码块复制 + 语法高亮（highlight.js）、上滚暂停自动滚 + 「跳到最新」浮按、推理流完自动折叠 + 「复制思考」、图片拖拽/粘贴入对话栏、首回 AI 完整后**生成 6-14 字短标题**（不再截开头废话）、对话内直接导出（Markdown / JSON / Word）、错误改 Alert + 重试按钮、Markdown 渲染补 LaTeX 数学公式（KaTeX）。
- **AI 分析 · 设置与接口**：API Key 改 Password 输入（眼睛切换 + 粘贴去空白）、连接 chip 显延迟与失败详情 Tooltip、Provider「高级」三段折叠（模型/鉴权/请求体）、Provider 列表「卡片/紧凑」视图切换、新 Provider 保存自动拉模型列表。
- **AI 分析 · 资料 / 模板 / 组合**：资料全 pane 拖拽上传 + 非阻塞批量队列进度条 + 重复文件一次性决策（覆盖/跳过/全部覆盖/全部跳过）、资料卡片/列表视图切换、文件夹管理 Drawer（CRUD + 「移动到」）、模板编辑加变量推断侧栏 + JSON Schema 实时校验、模板版本 diff 弹层、组合包「应用预览」。
- **AI 分析 · 后端补齐（需重编 jar，已重编）**：用量/费用计量（SSE 新 `usage` 事件覆盖 OpenAI/Anthropic/Gemini/Ollama，消息底显示 token 与估算成本）；Gemini 视觉补齐（`inlineData`/`fileData`）；Anthropic/Gemini/Ollama 停止序列 / JSON 模式 / 思考档**显式映射**而非透传；`isReasoningModel` 前后端同步覆盖 gpt-5/6/7、o1/3/4/5/6/7。
- **AI 分析 · 历史 tab 重做**：表头紧凑、列宽固定、操作收成「导出 ▾」下拉；按条件渲染独立空态。
- **导出/挂载 · 七政四余补「政余格局/相位」**：右栏 Moira 面板已显示但此前未导出/挂载的两段补齐（`AI_EXPORT_SETTINGS_VERSION` 22→23 自动迁移）。
- **导出/挂载 · 五兆/太玄筮法/荆诀/神易数补 AI 挂载**：四种确定性起卦术此前已可存事盘却挂不上，本版补齐。
- **修复 · 「分至」星盘样式按钮失效**：根因是 `<JieQiChartsMain>` 与内层 `<AstroChartMain>` 漏传 `chartStyle`/`dispatch`，导致样式切换为空操作。补两处 props 即修。
- **修复 · 多处稳定性问题**：修若干 Dropdown `overlay={JSX}` 导致的「state update on unmounted」内存泄漏；资料批量导入末段卸载安全；模板版本 diff 空版本兜底；图片上传 onerror + 10MB/张上限。

> **关于 Windows issue #20**（@zuojun1991 2026-06-07）：(1) 聊天过程中挂载新内容被截断 = AI 分析后端用量/思考档显式映射前，部分 Provider 的请求体溢出长 context；本版 `usage` 事件 + 显式 JSON 模式 + 思考档映射后已稳定。(2) 太阳返照 AI 只有本命盘信息 = 七政四余/西占推运挂载的「导出口径」修复（七政四余「政余格局/相位」补齐 + Qizheng 推运盘的挂载 schema 修订），本版可正常挂返照盘。
