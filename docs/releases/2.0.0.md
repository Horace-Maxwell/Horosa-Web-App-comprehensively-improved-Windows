# Horosa 2.0.0 Beta

## Release Focus

- Current release / 当前发布版本: `v2.0.0 Beta`
- `v2.0.0 Beta` is the Windows Mac Web parity release.
- `v2.0.0 Beta` 是 Windows 端与新版 Mac Web 全面统一的大版本。
- Beta note / Beta 说明: this installer is published as a visible GitHub Release so Windows users can download and test the unified Web/Desktop build directly.

## What Changed

- Synchronized the improved Web product surface into Windows: UI shell, module navigation, frontend pages, Python services, Java services, resources, and desktop delivery.
- Replaced the older README sample images with the three v2.0.0 screenshots: main astrology workspace, module navigator, and Sanshi workspace.
- Updated the XQ UI shell, icon system, day/night appearance, search, favorites, history, settings, help, quick actions, AI export entry, and module selector.
- Added or aligned Web modules for natal astrology, timing, relationship charts, auxiliary charts, Indian astrology extensions, Qizheng Moira, planetarium/3D, Sanshi, Liu Ren, Dun Jia, Tai Yi, Bazi, Ziwei, Feng Shui, and calendar workflows.
- Expanded AI Analysis and AI export settings with module snapshots and provider/material/chat/embedding/stream service paths.
- Added Python backend routes and resources including `/astroextra`, `/planetarium`, supporting ephemeris services, star resources, and Indian astrology extensions.
- Added Java backend routes and services including `/astroextra/*`, `/planetarium/state`, `/qizheng/moira`, and AI Analysis provider/material/chat/embedding/stream wiring.
- Kept the Windows-specific bundled runtime, launcher, and installer adaptations required for clean-machine use.
- Removed release-facing dependence on the old `Horosa-Web-App-comprehensively-improved-MacOS-main` sync source folder.
- Beta hotfix: fixed clean-machine desktop startup failures caused by packaged `pyswisseph.azalt` API differences, added a Java logging path fallback, and prevented harmless Electron `ERR_ABORTED` loading-page switches from surfacing as fatal startup dialogs.
- Beta hotfix: fixed the Feng Shui module blank page in the packaged desktop/file-mode build by resolving its embedded static page relative to the active renderer URL.
- Beta hotfix: removed visible desktop-window jitter during startup by skipping redundant post-show maximize normalization passes once the window is already maximized.
- Added a desktop startup repair action that clears damaged embedded-runtime and health caches, then restores the bundled runtime from the installer payload.
- Installer hardening: the v2.0.0 Beta NSIS flow now supports user-selected install directories, elevation when Windows requires it, first-install guidance, directory creation/write validation, and regression coverage for custom install paths plus repaired shortcuts.

## Installation

- Recommended download / 推荐安装包: `Horosa-Setup-2.0.0.exe`
- Platform: Windows 10/11 x64
- Distribution: NSIS installer with bundled runtime payload
- Expected clean-machine behavior: no separate Python, Java, Node.js, Maven, or frontend toolchain install is required for normal use
- Install directory: default path remains `%LocalAppData%\Programs\Horosa`, and users can choose another writable directory in the assisted installer
- Release channel: public beta / 发布通道：公开 beta

1. Download `Horosa-Setup-2.0.0.exe` from this release.
2. Run the installer, optionally choose an installation directory, and open Horosa normally.
3. Allow extra time for the first launch while the bundled runtime initializes.
4. Existing app data is expected to remain in place during app replacement.
