## Summary / 概览

`v2.1.1 Beta` is the Windows clean-machine hardening release for the Mac 2.1.0 beta parity work. It keeps the full 2.1 product surface, then fixes the native Windows runtime packaging gap that could make a clean machine fail before the Python chart service was ready.

`v2.1.1 Beta` 是 Mac 2.1.0 beta 对齐版之后的 Windows 干净机器加固发布。它保留 2.1 的完整功能面，并修复干净 Windows 机器上因原生运行时缺失导致 Python 图表服务无法启动的问题。

## What Changed / 本轮重点

- Bundled Python now uses a pinned `python-build-standalone` runtime by default, reducing drift from the build machine's locally installed Python.
- The installer payload vendors Microsoft VC++ 2015-2022 x64 runtime DLLs beside bundled `python.exe`, especially `msvcp140.dll`, so `swisseph`, `_sxtwl`, and other installed native extensions can load without requiring users to install VC++ Redistributable.
- `stage-runtime.cjs` injects the VC++ runtime DLLs again during staging and runs `check_runtime_native_deps.py`; missing non-system DLL imports now fail the build before a broken installer can be published.
- Electron startup handling now reports the real crashed service and preserves the sibling-process shutdown boundary, reducing false "Java backend exited" reports when the actual failure is Python native dependency loading.
- The startup/error screen, installer icon, header/sidebar art, and displayed app name were refreshed around the latest XingQue/Horosa branding.
- `npm run verify` is now part of the `dist:win` gate and checks service-manager tests, release metadata, brand assets, VC++ runtime presence, and Windows display-name expectations.

## 2.1 Feature Surface Kept / 保留的 2.1 功能面

- Mac 2.1.0 beta UI, frontend, Python backend, Java backend, icons, and traditional-method modules are retained on Windows.
- Taiyi, Jin Kou, Huangji/Wangji, Wuzhao, Taixuan, Jingjue, Shenyishu, Kin Astro, Qizheng, Qimen, and related traditional-method endpoints remain included.
- Sanshi United keeps the corrected routing: Qimen and Taiyi use kentang backends, Liuren stays local, and unsupported Yuejia Qimen is not exposed as a stale fallback.
- Chart and case management preserve tags, snapshots, raw structured backend payloads, JSON import/export, and reopen restore behavior.
- AI export keeps structured technique/tab segmentation from backend data.
- Ziwei four-transform chart hides star brightness labels, while Ziwei Sanhe and Cetian Feixing keep brightness where appropriate.
- XingQue Bazi fine-chart upper content can scroll without covering the fixed luck/flow selector.
