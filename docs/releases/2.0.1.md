# Horosa 2.0.1 Beta

## Summary

- Current release / 当前发布版本: `v2.0.1 Beta`
- GitHub Release title/body says Beta, but the release is intentionally **not** marked as a GitHub prerelease so Windows users can see it from the repository Release area.
- `v2.0.1 Beta` keeps the Windows 2.0 desktop delivery track and syncs the latest Mac Qimen Dunjia repair set into the Windows Web/Desktop package.

## Main Fix

Qimen Dunjia has been realigned with the latest Mac build that passed the mobile-algorithm parity work.

- Chaibu and Zhirun are handled as separate modes and no longer share a forced one-path correction.
- Ju selection follows accurate Jieqi switching by hour/minute/second instead of a coarse date-only boundary.
- Real-solar-time pillars and local calendar fallback data are used where the real backend cannot provide the exact fields.
- Tianpan stems, Dipan stems, doors, gods, stars, Zhifu/Zhishi, Xunkong, and Shensha output follow the Mac/mobile-aligned path.
- The desktop UI keeps the same Qimen page behavior while the calculation path is now the current Mac source of truth.

奇门遁甲已同步 Mac 端已通过的最新版修复：

- 拆补与置润分别对齐，不再把两种排盘法混成同一套补丁。
- 起局按精确交节时刻判断，避免只按日期或粗略“白露/秋分”区段造成偏差。
- 真太阳时四柱与本地历法回退优先复用已有历法能力。
- 天盘干、地盘干、门、神、星、值符值使、旬空与神煞输出按 Mac / 手机版对齐路径计算。
- 前端页面保持 Windows 2.0 统一外壳，计算核心同步到当前 Mac 权威版本。

## Windows Delivery

- Recommended download / 推荐安装包: `Horosa-Setup-2.0.1.exe`
- Supported platform / 支持平台: Windows 10/11 x64
- Normal users do not need to install Python, Java, Node.js, Maven, or frontend toolchains.
- The installer remains an NSIS assisted installer with custom directory selection, directory write checks, elevation support when Windows requires it, and bundled runtime delivery.
- First launch can still be slower while the bundled runtime initializes; later launches reuse the local runtime cache.
