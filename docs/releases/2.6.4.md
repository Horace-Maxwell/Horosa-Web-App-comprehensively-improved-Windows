## Windows issue #21 修复说明

@1sHyc 反馈：点击排盘报「排盘失败：本地排盘服务未就绪」，点「自建修复并重启服务」后仍无法排盘；不知道在哪里查看本地服务的运行状态。

诊断显示：app v2.6.2，启动曾失败 `Timed out waiting for port 8899`（Python 排盘服务 60 秒内未起来）→ 触发 `Repairing embedded runtime cache`，修复后多次成功就绪但启动很慢（曾耗时 159s / 106s）。日志另见 `${env:HOME}/.horosa-logs/...` 写日志失败（Windows 环境变量 HOME 是空的）。

v2.6.4 的根因式解决：
1. **首启长解压窗口**：透明重试 12s→30s，覆盖 35-60s 慢机首启
2. **「不知道在哪查看状态」**：右下角常驻 🟢/🟡/🔴 健康灯 + Popover「立即重试 / 重启后端 / 打开诊断中心 / 复制信息」
3. **「不知道点哪」**：排盘失败 Modal 列 4 类原因 + 4 个一键操作（取代原本只显错误标题）
4. **启动覆盖层分阶段文案**：6s 安静 → 15s 加重试 → 30s+ 显示后端地址 + 打开诊断中心
5. **断线横幅加操作按钮**：从「操作将自动重试…」升级到带「立即重试 / 重启后端 / 打开诊断」
