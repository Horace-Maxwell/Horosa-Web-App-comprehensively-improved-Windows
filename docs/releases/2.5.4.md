# Horosa v2.5.4 Beta — 发布说明

> **同步 macOS 端 v2.5.4 产品面 + Windows 启动稳健化镜像清单**：七政四余二十八宿度三制对齐、主限法 v10 全方位法（四宫位法 + 真太阳弧 + 顺逆同选 + 映点 + 界）、量化盘汉堡补全；并镜像 macOS 已做的启动稳健化共享层 + 三项 Windows 独有改动（trusted 路径真心跳 / Job Object 防孤儿后端 / Java 绑 127.0.0.1 防防火墙弹窗）。v2.5.3 及更早全部功能保留。

## 加固补丁（v2.5.4 原地覆盖重发 · Windows 安装/更新/健康检查对齐成熟软件）

> 本次为 **v2.5.4 原地覆盖**（**不 bump 版本号**）：以下 5 项是 Windows 独有的「安装 + 更新 + 健康检查」机制加固，影响的主要是**未来版本怎么发**（发布基建）与**客户端自我保护**，产品功能与上面 v2.5.4 完全一致。详见 [docs/auto-update-windows.md](../auto-update-windows.md) 的「v2.5.4 加固」章。

- **① 更新链路安全 — Ed25519 签名更新元数据（fail-closed）**：在不依赖任何 CA 的前提下，用一对**离线** Ed25519 密钥给「下载下来的安装包」背书。私钥永不进仓/CI，公钥内置客户端。客户端下完更新后，**先**算安装包 sha512 → 拉 release 的 `horosa-update.sig` → 内置公钥验 `版本+哈希`，**验过才允许安装**；验不过/拉不到签名一律拒装并提示手动下载。同时把 `autoInstallOnAppQuit` 关掉，杜绝「退出时自动装」绕过验签的旁路。把「GitHub release 被替换 / HTTPS 被 MITM → 用户权限自动装上恶意 exe」这条 Electron updater 经典 RCE 通道，收敛为「**还需拿到离线私钥**」。
- **② 发布安全 — 灰度发布 + 通道**：新增 `scripts/set-staging.cjs` 给线上 `latest.yml` 注入 `stagingPercentage`，支持 10%→25%→50%→100% 逐步放量、先在子集发现回归（`allowDowngrade=false`、`channel=latest` 显式写明）。
- **③ 带宽 — 差分下载**：`disableDifferentialDownload=false` 显式保持开启 + 每版发 blockmap，小版本更新只下变化块。
- **④ 健康检查 — 运行期后端崩溃自动重启（H-7）**：ready 之后 python/java 崩溃时**有界自动重启**（≤2 次 + 退避，稳定 45s 清零预算；计划内关闭/更新期不重启），耗尽才落到手动 repair。配合 v2.5.4 Job Object 自动纳管重启出来的新子进程。
- **⑤ 分发 — winget**：新增 `scripts/winget-manifest.cjs` 生成 winget manifest，加一条 `winget install HoraceMaxwell.Horosa` 路径（不替换 NSIS 下载）。
- **暂缓（owner 决策）**：代码签名（消除 SmartScreen——便宜的 Azure Trusted Signing 中国不可用、不买 EV 证书）与 CI 化发布维持现状。

> **传播口径**：发布基建（签名管线/灰度/差分/winget）只影响未来版本怎么发，本不需推给现有用户 → 原地覆盖正确；客户端内两项（Ed25519 验签器 + H-7 自动重启）按覆盖只对**新下载**生效，验签器本就该「先于它要验的更新进客户端」，下个真版本签名发布时新装/覆盖的客户端即可验签，H-7 随之铺开 → **本轮无需 bump**。覆盖重发已重生成 exe/blockmap/latest.yml/SHA256SUMS **并重签 `horosa-update.sig`**（下表哈希为重发后的新值）。

## 本次更新

### 七政四余「二十八宿度」三制对齐
- **新增三制**：回归今制（活体距星严格岁差）/ 回归古制（开禧基值 + 岁差）/ 恒星制（郑氏恒星基值原值）。
- **修复**：回归今制原误用郑氏恒星冻结值 15.9（偏 ~18°），现已改为**活体距星**，实拍核对恒星制 10 颗到角分。
- **命度红线**：七政 Moira 命度红线加宿度带一条，落宿位置一目了然。

### 主限法 v10 全方位法（P1~P4 完成）
- **四方位法**：Alchabitius / Placidus（半弧）/ Regiomontanus / Campanus / Topocentric / Horosa原方法。Alchabitius 路径**逐字节对拍通过**（v2.5.3 表格行 = v2.5.4 默认 Alchabitius + Ptolemy 表格行 byte-identical）。
- **真太阳弧（True Solar Arc）**：取代 v2.5.3 的拟合常数。表格与盘均支持。
- **顺逆同选**：默认改为「顺逆都开」（用户偏好；Alcabitius + Ptolemy 表格行不变）。
- **映点（Antiscia）/ 界（Terms）**：可勾选包含。
- **time-key 收敛**：撤除 v2.5.2/v2.5.3 的拟合常数（Cardano / Plantiko / Wöllner / SymbolicSolarArc）、删 `fit_pd_constants.py`，留下可证明的 **Ptolemy / Naibod / 真太阳弧** 三项。
- **后端 Java 改动**：`PredictiveController.getParams()` 补 `pdDirect / pdConverse / pdAntiscia / pdTerms` 透传 + `_wireRev` v8 → v10，让旧 `ParamHashCache` 缓存失效（**根治**「推运方向选了没用」的真因——直顺/逆向 params 哈希相同 → 命中同缓存）。**已重建 jar**。
- **主限法盘四角赤纬归正**：ASC / MC / DESC / IC 一律 `_pdChartEqCoords(lon, 0.0, obliquity)`（修长期误用地理纬度作黄纬导致赤纬越界）。

### 量化盘 90° 中点盘补全（汉堡学派全面补全与纠错）
- 新增 `UranianGraphicEphemeris`（图形星历）与图层完善。
- 配套 11 例新测试，覆盖各方位法 / time-key 组合。

### Windows 启动稳健化（镜像 macOS + 三项 Windows 独有，根治启动期最大类用户反馈）
- **① 修「白屏 / 进不去主界面」**：trusted 快路径不再「仅端口探测」，改发**真 HTTP `/heartbeat`** 验后端就绪；短超时失败时退回完整就绪等待，**绝不先加载 UI**。镜像 macOS `start_horosa_local.sh` 一律 HTTP 轮询的口径。
- **② 修「端口被占用 / 孤儿后端」**：新增 **Windows Job Object KILL_ON_JOB_CLOSE**（基于 koffi 调用 Win32 API）。Electron 一旦退出（含崩溃 / OOM / 外部 taskkill），OS 自动连带终止内置 python.exe / java.exe，杜绝孤儿后端占口。失败自动回退到现有 taskkill / findPort 双保险，**绝不阻断启动**。镜像 macOS 进程组 setpgid + killpg。
- **③ 修首启「防火墙弹窗」**：Spring Boot 加 `--server.address=127.0.0.1`，只绑本机回环。Java 仅被渲染进程经 127 访问，Mongo / Redis / AI 是客户端外连不受影响。**不动**共享 `application.properties`，仅命令行 arg 桌面专属、零波及服务器部署仓库。镜像 macOS launcher。

### 其它（v2.5.4 配套小补）
- **AI 四同步**：导出设置版本 15→16（触发旧 presets 回收）；主限法不再硬编码覆盖 pdMethod/pdTimeKey（透传 chartObj.params 实选，LLM 上下文跟随用户选择）。
- **PD_SYNC_REV**：前端升 `pd_method_sync_v10`、与后端 + Java `_wireRev` 对齐，强制旧 v8/v9 缓存重算。
