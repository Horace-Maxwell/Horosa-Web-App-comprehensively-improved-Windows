# Horosa v2.6.1 Beta — 发布说明

> **同步 macOS 端 v2.6.1**：AI 挂载全选项打磨（每技法「设置」齿轮抽屉，schema 驱动，无遗漏）+ 多时段 / 区间扫描输出 + 风水八卦阳宅法 v2（倪海厦，纯前端）+ 一批跨模块修复。**唯一后端改动** = `ChartController.getParams()` 转发 `pdYears` + `pd*`（挂载侧主限法年数选项生效的真因）+ `_wireRev v8→v9` → **已重建 `astrostudyboot.jar`**。所有技法命盘计算与 v2.6.0 字节级一致；v2.6.0 及更早全部功能保留。

## 本次更新

- **AI 挂载全选项**（前端）：新增 `utils/techniqueMountSettings.js`（`TECHNIQUE_SETTINGS_SCHEMA` 驱动的齿轮抽屉），`AIAnalysisMain.{js,less}` 渲染每技法「设置」抽屉 + 内容勾选；**多时段日期选择器 + 区间扫描**输出。零回归铁律「默认即现状」（等于默认的项被 prune，快照逐字节不变）。
- **主限法挂载年数生效**（后端 → 重建 jar）：`astrostudycn/.../controller/ChartController.java` 的 `getParams()`（`/chart` 路径，AI 挂载用）此前**丢弃** `pdYears` + `pdDirect/pdConverse/pdAntiscia/pdTerms`，导致挂载主限法选项不生效；修法 = 条件转发（缺省零回归）+ `_wireRev` `pd_method_sync_v8→v9`（让旧 ParamHashCache 失效）。
- **风水 · 八卦阳宅法 v2（倪海厦，纯前端）**：`components/fengshui/{FengShuiMain,fengshuiEngine}.js` + 新增 `{baguaCore,baguaData,naqiRules,fengshuiGeom}.js` + 罗盘皮肤 `public/fengshui/skins/`；默认仍纳气盘（`techMode='naqi'`），逐字节零回归。
- **多盘 / 多时段补全**：占星各推运 builder（`components/astro/*`）、主限法盘表拆分、紫微 `ZiWeiMain`/`ZWLuckPanel`、八字 `BaZi.js`、六爻三卦全装卦 + 一键挂载（`guazhan/GuaZhanMain.js`）。
- **跨模块修复**：辅盘样式切换失效（`DivinationChartShell.changeChartStyle` 误把事件对象当值）；三式「时空」中点盘端口兜底（`AstroRelative.js` `:9999→:8899`）；主题 / 布局 / 暗黑双色快修（`app.less`）。

## 同步与构建口径（Windows）

- **同步范围**：仅 `Horosa-Web/` 业务改动——前端 `astrostudyui/**`（含 `public/fengshui/skins/*.png` 资产）+ 唯一后端 `astrostudycn/.../ChartController.java`。
- **后端改动 → 重建 jar**：`astrostudycn install → astrostudyboot clean package`；验内嵌 `astrostudycn-1.0.0.jar` 的 `ChartController` 含 `pdYears`/`pd_method_sync_v9`。**重建前端包**（`dist:win` 的 `build:renderer`）。`windows-adaptations/apply.sh` 全恢复（boundless `isLoopbackTarget` 自动 no-op）。
- Mac 同步基线 `af5126db3`（v2.6.0）→ HEAD `fc7ab745b`（v2.6.1）。**下次 Mac 同步基线 = `fc7ab745b`**。
